# สเปกเฟส 1 — โหมดฝึกพูด (ออฟไลน์ล้วน ไม่ใช้ AI)

> สถานะ: **อนุมัติแล้ว — ขั้น 1+2 เสร็จแล้ว** (บทสนทนาจำลองใช้งานได้จริง) · ขั้น 3–7 รอดำเนินการ
> เป้าหมาย: ผู้ใช้ "พูดภาษาอังกฤษในชีวิตประจำวันได้" โดยไม่เน้นไวยากรณ์
> ข้อกำหนดที่ตกลงแล้ว: **ไม่ใช้ AI, ไม่มี backend, ทำงานออฟไลน์ได้, ข้อมูลอยู่ในเครื่องผู้ใช้**
>
> **ผลที่ทำเสร็จแล้ว**
> - เนื้อหา: 8 สถานการณ์ · 79 บรรทัด · 39 ประโยคที่ผู้ใช้พูดเอง · ใช้คำศัพท์จากชุด 96 คำ 91 คำ
> - หน้าจอ: ศูนย์รวม "ฝึกพูด" (แทนแท็บเกม) · บทสนทนาจำลอง · ทบทวนประโยค (SRS ระดับประโยค)
> - ระบบ: ให้คะแนนจากการพูดจริง · สลับบท · แผงอธิบายก่อนขออนุญาตไมค์ · โหมดไม่ให้คะแนน · บันทึกความคืบหน้า
> - **บันทึกเสียงผู้ใช้ + ฟังย้อนหลังเทียบเสียงต้นแบบ (A/B)** — เก็บใน IndexedDB ของเครื่อง (โควตา 30 คลิป / 20 MB ลบเก่าสุดอัตโนมัติ)
> - **สอนออกเสียงคำที่ยังไม่ชัด**: ชี้คำที่พูดไม่ตรง → แตะเพื่อฟังช้าๆ + IPA/คำแปล/ภาพ (ถ้ามีในคลังคำศัพท์) + โหมดฝึกทีละคำจนครบ
> - **ประตู "พูดจนกว่าจะผ่าน"**: ต้องถึงเกณฑ์ (ค่าเริ่มต้น 70%) ก่อนไปประโยคถัดไป · ปรับเกณฑ์ได้ · ข้ามได้หลังลอง 3 ครั้ง
> - ทดสอบ: E2E 99/99 ผ่าน (รวมการจำลองไมค์และเสียงพูดเพื่อทดสอบวงจรการพูดจริง) · ทำงานออฟไลน์ได้
>
> **ยังเหลือ (ขั้น 3–7)**: พูดตามเงา · พูดคนเดียว 60 วินาที (ใช้ตัวบันทึกเสียงที่มีแล้ว) · เขียนจากเสียง · เรียงประโยค · ภารกิจวันนี้

## 2. ข้อจำกัดทางเทคนิคที่ต้องรู้ก่อนอนุมัติ

| # | เรื่อง | ความจริง | ทางออกที่เสนอ |
|---|---|---|---|
| T1 | **พูดตามเงาแบบพร้อมกัน (true shadowing) ให้คะแนนอัตโนมัติไม่ได้** | ระหว่างเล่นเสียงออกลำโพง ไมค์จะได้ยินเสียงตัวเองปนกับเสียงต้นแบบ และ Web Speech API ไม่มี echo cancellation ที่ควบคุมได้ | **โหมด A: พูดพร้อมกัน** = อัดเสียงไว้ แล้วให้ผู้ใช้ "ฟังเทียบ A/B" ด้วยหูเอง (ไม่ให้คะแนน) · **โหมด B: ฟัง–หยุด–พูดตาม** = ให้คะแนนได้ (แนะนำเป็นค่าเริ่มต้น พร้อมคำแนะนำ "ใส่หูฟังเพื่อโหมดพร้อมกัน") |
| T2 | **STT ไม่มีใน Firefox** | `SpeechRecognition` รองรับ Chrome/Edge/Safari (บางส่วน) | ทุกโหมดต้องมี **"โหมดไม่ให้คะแนน"**: ฟังต้นแบบ → อัดเสียงตัวเอง → ฟังเทียบ → ให้คะแนนตัวเอง 1–5 (ผู้ใช้ Firefox/เบราว์เซอร์ในแอป LINE จะยังใช้ได้ครบ) |
| T3 | **ไมค์ต้องเป็น HTTPS/localhost** | เปิดไฟล์ตรงๆ (`file://`) ใช้ไม่ได้ | แสดงหน้า **"อธิบายก่อนขออนุญาต"** (ทำไมต้องใช้ไมค์ + ข้อมูลอยู่ในเครื่อง) ก่อนเปิดไมค์จริง → ลดอัตราการกดปฏิเสธถาวร |
| T4 | **พื้นที่จัดเก็บเสียงจำกัด** | เสียง 60 วิ ≈ 0.3–0.8 MB | เก็บสูงสุด **30 คลิป หรือ 20 MB** (แล้วแต่จำนวนใดถึงก่อน) ลบเก่าสุดอัตโนมัติ · แสดงพื้นที่ที่ใช้ในหน้าตั้งค่า · ปุ่มลบทั้งชุด |
| T5 | **TTS กับ STT ใช้พร้อมกันมีปัญหา** | Chrome อาจตัดเสียงหรือได้ผลเพี้ยนเมื่อเล่นเสียงขณะไมค์เปิด | กำหนดลำดับชัดเจน: **ห้ามเล่น TTS ขณะ STT ทำงาน** (ยกเลิกเสียงก่อนเริ่มฟังเสมอ) — มีอยู่ในโค้ดปัจจุบันแล้ว (`stopSpeaking()` ก่อนเริ่มอัด) |
| T6 | **iOS Safari** | `MediaRecorder` ได้ฟอร์แมต `audio/mp4`, TTS บางเสียงต้องมี user gesture ก่อน | ตรวจ `MediaRecorder.isTypeSupported()` แล้วเลือกฟอร์แมตที่ใช้ได้ · ทุกการเล่นเสียงต้องมาจากการแตะของผู้ใช้ |
| T7 | **ขนาดข้อมูลบทสนทนา** | 8 สถานการณ์ × 10 บรรทัด ไม่ใหญ่ | เก็บใน `data/dialogues.json` แคชผ่าน service worker เหมือนไฟล์อื่น |

## 3. โครงสร้างข้อมูลใหม่

### 3.1 `data/dialogues.json` (สร้างจาก `data/raw/dialogues/*.json` ด้วยสคริปต์)

```json
[
  {
    "id": "dlg-cafe",
    "title": "สั่งกาแฟ",
    "titleEn": "Ordering coffee",
    "level": "A2",
    "emoji": "☕",
    "category": "restaurant",
    "setting": "คุณยืนอยู่หน้าร้านกาแฟ ต้องสั่งเครื่องดื่มและจ่ายเงิน",
    "imageQuery": "coffee shop counter barista",
    "commonsCategory": "Coffeehouses",
    "lines": [
      {
        "who": "staff",
        "en": "Hi, what can I get for you?",
        "thai": "สวัสดีครับ รับอะไรดีครับ",
        "keyPhrases": [
          { "en": "what can I get for you", "thai": "รับอะไรดีครับ" }
        ]
      },
      {
        "who": "me",
        "en": "Could I get a medium latte, please?",
        "thai": "ขอลาเต้แก้วกลางครับ",
        "keyPhrases": [
          { "en": "Could I get", "thai": "ขอ...ครับ (สุภาพ)" },
          { "en": "a medium latte", "thai": "ลาเต้แก้วกลาง" }
        ],
        "alternative": [
          { "en": "I'd like a medium latte, please.", "thai": "ผมขอลาเต้แก้วกลางครับ" },
          { "en": "Can I have a latte, please?", "thai": "ขอลาเต้ครับ" }
        ]
      }
    ],
    "usefulPhrases": [
      { "en": "For here or to go?", "thai": "ทานที่ร้านหรือกลับบ้าน" },
      { "en": "Keep the change.", "thai": "ไม่ต้องทอน" }
    ]
  }
]
```

**กฎการเขียนเนื้อหา** (บังคับ ตรวจด้วยสคริปต์)
- 8–10 บรรทัดต่อสถานการณ์ สลับบท `staff`/`me` เริ่มด้วย `staff` เสมอ
- ประโยค `me` ยาว 4–12 คำ · ระดับ A2 · **ต้องเป็นประโยคที่คนจริงพูด** ไม่ใช่ประโยคตำรา
- ทุกบรรทัดมี `thai` (ภาษาพูด อ่านลื่น)
- `keyPhrases.en` ต้องเป็น **สตริงย่อยที่ปรากฏจริง** ในประโยค (เหมือนที่ทำกับคำศัพท์แล้ว)
- ทุกรอบ `me` ควรมี 2–3 `alternative` (ประโยคทางเลือกที่พูดแทนได้)
- **ห้ามมีคำอธิบายไวยากรณ์** — ถ้าจำเป็นให้ใส่เป็น "เคล็ดลับการใช้" สั้นๆ ไม่เกิน 60 ตัวอักษร
- คำศัพท์ในบทสนทนาควรซ้ำกับ 96 คำที่มีอยู่ ≥ 60% เพื่อให้ SRS เชื่อมกัน

### 3.2 โครงสร้างใน `localStorage` (เพิ่มจากเดิม)

```js
{
  srsSentences: {
    "dlg-cafe:2": { ease: 2.5, interval: 0, reps: 0, lapses: 0, due: 0, last: 0 }
  },
  daily: {
    "2026-10-17": { reviewed: 0, correct: 0, newWords: 0,
                    spoken: 0,        // จำนวนครั้งที่พูดออกเสียงจริง
                    dialogues: 0,     // สถานการณ์ที่เล่นจบ
                    selfRatings: [],  // [1..5] ของโหมด 60 วินาที
                    secondsSpoken: 0 }
  },
  speaking: {
    shadowMode: "sequential",   // sequential | simultaneous
    recordEnabled: true,
    questGoal: { sentences: 15, dialogues: 1, seconds: 60 }
  }
}
```

**IndexedDB** (ฐานข้อมูลใหม่ `picenglish-audio`)

```
objectStore "recordings"  keyPath "id"
  { id, kind: "onemin" | "shadow" | "roleplay", refId, createdAt,
    seconds, mime, blob, selfRating }
index "createdAt"
```

## 4. หน้าจอ (wireframe ย่อ)

### 4.1 บทสนทนาจำลอง — เลือกสถานการณ์

```
┌─────────────────────────────┐
│ ←  บทสนทนาจำลอง        ⚙️  │
├─────────────────────────────┤
│  [☕] สั่งกาแฟ             │
│       Ordering coffee · A2  │
│       ฝึกแล้ว 2 ครั้ง  · 80%│
│  [🍽️] สั่งอาหารในร้าน      │
│  [🛏️] เช็คอินโรงแรม        │
│  [🧭] ถามทาง / ขึ้นรถ       │
│  ...                        │
├─────────────────────────────┤
│ 🎯 เป้าวันนี้  พูด 3/15 ประโยค│
└─────────────────────────────┘
```

### 4.2 บทสนทนาจำลอง — เล่น

```
┌─────────────────────────────┐
│ ←  สั่งกาแฟ            2/8  │
│ ▓▓▓▓░░░░░░░░░░░░░░░░░░░░    │
│  ☕ ภาพร้านกาแฟ   (บริบทไทย)│
├─────────────────────────────┤
│  🧑 Barista                 │
│  ┌───────────────────────┐  │
│  │ Hi, what can I get    │  │
│  │ for you?         🔊  │  │
│  │ สวัสดีครับ รับอะไรดีครับ│  │
│  └───────────────────────┘  │
│            🙋 คุณ (บทของคุณ) │
│        ┌──────────────────┐ │
│        │ Could I get a    │ │
│        │ medium latte,    │ │
│        │ please?       🔊 │ │
│        └──────────────────┘ │
│  วลีสำคัญ: [Could I get][a medium latte]
│                             │
│        ( 🎤 กดค้างเพื่อพูด ) │
│   คะแนน 82% — ผ่าน! ✅       │
├─────────────────────────────┤
│ [🔁 ฟังอีกครั้ง] [⏭ ข้าม] [💡 ทางเลือก]│
└─────────────────────────────┘
```

**ขั้นตอน**
1. แสดงบริบทไทย 1–2 บรรทัด (ไม่ให้อ่านบทล่วงหน้านาน — ลดภาระความจำ)
2. **แอปอ่านบทคู่สนทนาอัตโนมัติ** (ไฮไลท์คำแบบคาราโอเกะ — ใช้โค้ดเดิม)
3. ถึงบทของผู้ใช้: แสดงประโยค + ปุ่มไมค์ → กดแล้วพูด
4. ให้คะแนนด้วย `alignWords()` ที่มีอยู่: **≥70% = ผ่าน**, 50–69% = "ลองอีกครั้ง", <50% = "ฟังต้นแบบแล้วลองใหม่"
   - **ข้ามได้เสมอ** (ไม่มีการบังคับผ่าน) — สำคัญต่อความรู้สึกของผู้ใช้
   - พูดผิดไม่ถือเป็นความล้มเหลว แต่ **บันทึกเข้าคิว SRS ประโยค**
5. จบ scenario → **สลับบท** ให้เล่นอีกรอบ (รอบ 2 = บทที่ยาว/ยากกว่า)
6. สรุป: "วันนี้คุณพูดได้ 6 ประโยค" + วลีที่ใช้ได้แล้ว + ปุ่ม "ฟังบทสนทนาทั้งหมด" (ให้รางวัลทางความรู้สึก)

**สถานะที่ต้องจัดการ**: ยังไม่อนุญาตไมค์ · เบราว์เซอร์ไม่รองรับ STT (→ โหมดไม่ให้คะแนน) · พูดแล้วไม่ได้ยิน (timeout 8 วิ) · ผู้ใช้ออกกลางคัน (บันทึกความคืบหน้าถึงบรรทัดล่าสุด)

### 4.3 พูดตามเงา (Shadowing)

```
┌─────────────────────────────┐
│ ←  พูดตามเงา                │
│  โหมด: [ฟัง–พูดตาม] [พูดพร้อมกัน]│
├─────────────────────────────┤
│  Their new house has a      │
│  small garden and a garage. │
│  บ้านหลังใหม่ของพวกเขามี...  │
│                             │
│  [ ▶ เล่นต้นแบบ ] 0.7× 1.0× │
│                             │
│      ( 🎤 พูดตามพร้อมกัน )   │
│  ⏺ อัดอยู่ 00:04 / 00:12    │
├─────────────────────────────┤
│  เทียบเสียง                  │
│  [🔊 ต้นแบบ]  [🔊 เสียงคุณ] │
└─────────────────────────────┘
```

- **โหมดฟัง–พูดตาม (ค่าเริ่มต้น, ให้คะแนนได้)**: เล่นประโยค → หยุด → ผู้ใช้พูด → ให้คะแนน (ใช้ `alignWords`)
- **โหมดพูดพร้อมกัน (ไม่ให้คะแนน)**: เล่นประโยคต่อเนื่อง + ผู้ใช้พูดพร้อมกัน → อัดเสียง → จบแล้วเทียบ A/B ด้วยหู · หน้าจอเตือนให้ใส่หูฟังก่อน
- ความเร็ว 0.7× / 0.85× / 1.0× (มีอยู่แล้วในโค้ด)

### 4.4 พูดคนเดียว 60 วินาที

```
┌─────────────────────────────┐
│ ←  พูดคนเดียว 60 วินาที      │
├─────────────────────────────┤
│  หัวข้อวันนี้                │
│  "เล่าเกี่ยวกับบ้านของคุณ"    │
│  ลองใช้คำ: living room,      │
│  kitchen, balcony, lamp      │
│                             │
│         ⏺ 00:37            │
│      ( 🎙 กำลังอัด… กดเพื่อหยุด )│
│                             │
│  ── คลิปของฉัน ──            │
│  🔊 17 ต.ค. · 60 วิ · ★★★★☆ │
│  🔊 16 ต.ค. · 52 วิ · ★★★☆☆ │
└─────────────────────────────┘
```

- หัวข้อสร้างจาก **คำที่ผู้ใช้เพิ่งเรียน/คำที่ยังไม่แม่น** (ไม่ต้องมี AI — สุ่มจาก SRS + เทมเพลตหัวข้อ)
- หลังอัด: เล่นย้อนหลัง → ให้คะแนนตัวเอง 1–5 → เก็บในเครื่อง
- **แฟ้มสะสมเสียง** = จุดขายทางจิตวิทยาที่แรงที่สุด (เห็นพัฒนาการตัวเองใน 1 เดือน)

### 4.5 เขียนจากเสียง (Dictation)
เล่นประโยค (TTS) → ผู้ใช้พิมพ์ → เทียบด้วย `sentenceSimilarity()` → แสดงผลต่างทีละคำ (เขียว/แดง) → ถ้าผิด ≥2 คำ เล่นซ้ำให้ฟังอีกครั้ง
**ได้อะไร**: ฝึก "ฟังออก → เขียนได้" ซึ่งเป็นทักษะเขียนทั่วไปที่ผู้ใช้ขอ โดยไม่ต้องสอนไวยากรณ์

### 4.6 เรียงประโยค (Sentence Builder)
แสดงชิปคำสลับที่ (พร้อมคำลวง 1–2 คำในระดับสูง) → ผู้ใช้แตะเรียงเป็นประโยค → ตรวจ → ถ้าผิดให้ชี้ "ตำแหน่งที่ผิด" ไม่ใช่เฉลยทันที
**ได้อะไร**: ฝึกโครงประโยคโดยไม่ต้องอธิบายไวยากรณ์ (เรียนจากรูปแบบ)

### 4.7 ภารกิจวันนี้ (Daily Quest) — หน้าจอหลักใหม่

```
┌─────────────────────────────┐
│  🎯 ภารกิจวันนี้      17 ต.ค. │
│  ▓▓▓▓▓▓░░░░░░  40%          │
├─────────────────────────────┤
│  ✅ ทวน 5 ประโยค            │
│  ⬜ สนทนา 1 สถานการณ์        │
│  ⬜ พูดคนเดียว 60 วินาที      │
│  ⬜ เขียนจากเสียง 3 ประโยค    │
├─────────────────────────────┤
│  สัปดาห์นี้คุณพูดไปแล้ว       │
│  42 ประโยค · 5 สถานการณ์     │
└─────────────────────────────┘
```

## 5. การปรับโครงสร้างเมนู (ต้องเลือก)

ปัจจุบันมี 5 แท็บ: `การ์ด · ฟังประโยค · เกม · ทบทวน · คำของฉัน`

**ตัวเลือก A (แนะนำ)** — เปลี่ยนแท็บ 3 เป็น **"ฝึกพูด"** และย้ายเกมเข้าไปอยู่ข้างใน

```
การ์ด · ฟังประโยค · [ฝึกพูด] · ทบทวน · คำของฉัน
                        └─ บทสนทนาจำลอง / พูดตามเงา / พูด 60 วิ / เขียนจากเสียง / เรียงประโยค / เกม(รวมเก่า) / ภารกิจวันนี้
```
*ข้อดี*: จำนวนแท็บเท่าเดิม · วาง "การพูด" เป็นแกนกลางของแอป · เกมยังเข้าถึงได้

**ตัวเลือก B** — เพิ่มแท็บที่ 6 "พูด"
*ข้อเสีย*: แท็บแน่นบนจอมือถือ ชื่อแท็บจะสั้นจนอ่านยาก

**ตัวเลือก C** — ยุบ "ฟังประโยค" เข้าไปในการ์ด แล้วใช้แท็บที่ 2 เป็น "ฝึกพูด"
*ข้อดี*: ลดความซ้ำซ้อน (ฟังประโยคซ้อนกับการ์ดอยู่แล้ว)

> ผมแนะนำ **A** — ไม่กระทบผู้ใช้เดิม และสื่อจุดยืนใหม่ของแอปได้ชัดเจน

## 8. เกณฑ์ยอมรับ (Acceptance Criteria) + การทดสอบ

จะเพิ่มการทดสอบ E2E อัตโนมัติ (ต่อจาก 77 ข้อเดิม) โดยอย่างน้อย:

| การทดสอบ | เกณฑ์ผ่าน |
|---|---|
| เลือกสถานการณ์แล้วเล่นจนจบ | ผ่านได้ครบทุกบรรทัดโดยไม่ต้องรีเฟรช |
| ให้คะแนนจากการพูด (จำลองข้อความ) | พูดตรง → ≥70% · พูดผิด → <50% และขึ้น "ลองอีกครั้ง" |
| ข้ามบรรทัดได้ | ปุ่มข้ามทำงาน และไม่บล็อกความคืบหน้า |
| สลับบท | รอบ 2 บทบาทกลับกันจริง |
| บันทึกความคืบหน้ากลางคัน | ออกแล้วกลับเข้ามา เริ่มที่บรรทัดเดิม |
| ไม่รองรับ STT | ขึ้นโหมดไม่ให้คะแนน ไม่มี error และยังเล่นจบได้ |
| อัดเสียง 60 วิ | ได้ Blob, บันทึก IndexedDB, เล่นย้อนกลับได้, ลบได้ |
| ลบอัตโนมัติเมื่อเกินโควตา | เก็บไม่เกิน 30 คลิป/20 MB |
| ไม่เล่น TTS ขณะไมค์เปิด | ตรวจว่า `speechSynthesis.speaking === false` ก่อนเริ่ม STT ทุกครั้ง |
| SRS ประโยค | พูดไม่ผ่าน → เข้าคิว · ผ่าน → ตั้งรอบถัดไปถูกต้อง |
| ภารกิจวันนี้ | ตัวเลขเพิ่มตรงกับการกระทำ (พูด/สนทนา/วินาที) |
| ยังทำงานออฟไลน์ | เปิดแอปตอนปิดเน็ตได้ทุกโหมดใหม่ |
| เมนูใหม่ | ทุกแท็บเข้าถึงได้ และเกมเดิมยังเล่นได้ |

## 9. ความเสี่ยงและวิธีลด

| ความเสี่ยง | ผลกระทบ | วิธีลด |
|---|---|---|
| STT แม่นน้อยกับสำเนียงไทย | ผู้ใช้ท้อเพราะได้คะแนนต่ำทั้งที่พูดถูก | ใช้เกณฑ์ผ่านต่ำ (70%) · ใช้ `alignWords` แบบ fuzzy (มีแล้ว) · **มีปุ่ม "ฉันพูดถูกแต่แอปฟังผิด"** เพื่อไม่ให้คะแนนนั้นเข้าสถิติ |
| ผู้ใช้กลัวไมค์ตั้งแต่แรก | ไม่เริ่มใช้โหมดใหม่ | หน้าอธิบายก่อนขออนุญาต + โหมดไม่ให้คะแนนเป็นทางเลือกที่มองเห็นชัด |
| เสียงอัดกินพื้นที่เครื่อง | แอปถูกเก็บกวาด/ผู้ใช้ไม่พอใจ | โควตา 30 คลิป/20 MB + ลบเก่าสุด + แสดงพื้นที่ใช้ + ลบทั้งหมดในคลิกเดียว |
| เนื้อหาบทสนทนาไม่เป็นธรรมชาติ | ผู้ใช้จำประโยคที่คนจริงไม่พูด | ใช้กฎเนื้อหา §3.1 + ให้คุณตรวจ 8 สถานการณ์ก่อนเผยแพร่ |
| หน้าจอเริ่มซับซ้อน | ผู้ใช้ใหม่หลง | ภารกิจวันนี้เป็นหน้าหลักเดียวที่บอกว่า "ต้องทำอะไรต่อ" |

## 11. สิ่งที่จะ **ไม่** ทำในเฟสนี้ (กันขอบเขตบาน)

- ไม่ใช้ AI/LLM ทุกกรณี · ไม่มี backend · ไม่มีบัญชีผู้ใช้ · ไม่ซิงก์ข้ามเครื่อง
- ไม่มีบทสนทนาเสรีที่ผู้ใช้พูดอะไรก็ได้ (ต้องมี AI — เก็บไว้เฟส 2)
- ไม่มีวิดีโอ/คลิปจริง · ไม่มีชุมชน/แชท
- ไม่มีคะแนนระดับเสียง (phoneme) แบบ ELSA — เราแข่งที่ "พูดได้ทุกวัน" และ "ไม่ต้องกลัวผิด"
- ไม่มี leaderboard/การแข่งขัน
