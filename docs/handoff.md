## 3. ถ้าเครดิต AI หมด — ทางเลือกทำงานต่อ

### 3.1 ตัวแอปไม่ต้องใช้เครดิตเลย
PicEnglish เป็น static PWA — **รันและใช้งานได้ฟรีตลอดไป** ไม่ต้องมี API, ไม่มี backend
```bash
cd english-picture-app
python3 -m http.server 5173      # Windows: python -m http.server 5173
```

### 3.2 ทางเลือกสำหรับ "ทำโค้ดต่อ"

| ทาง | ค่าใช้จ่าย | ข้อดี | ข้อเสีย |
|---|---|---|---|
| **เติมเงิน DeepSeek** ($2 ขึ้นไป) | ~74 บาท | ทำงานกับเอเจนต์เดิมต่อได้ทันที | ต้องมีบัตร/PayPal |
| **Codex CLI / Cursor + API key ของคุณเอง** | ตามการใช้จริง | ใช้ `AGENTS.md` ที่เตรียมไว้ได้เลย | ต้องติดตั้งบนเครื่องใหม่ |
| **โมเดลในเครื่อง (Ollama / LM Studio)** | ฟรี | ไม่มีค่าใช้จ่ายเลย | คุณภาพต่ำกว่า ต้องมี RAM/GPU พอ |
| **ทำเองด้วยมือ** | ฟรี | ควบคุมได้ 100% | ช้ากว่า |

> DeepSeek มีคู่มือ integration กับ Codex อยู่ที่ `api-docs.deepseek.com/quick_start/agent_integrations/codex`

### 3.3 เคล็ดลับประหยัดเครดิต (สำคัญ)
- **ทำงานช่วงออฟพีก = ถูกครึ่งราคา** — เวลาไทย: หลัง 17:00 ถึง 08:00 น. + เสาร์–อาทิตย์ (พีกคือ 08:00–11:00 และ 13:00–17:00 จ–ศ)

## 4. ตรวจคุณภาพได้เองโดยไม่ต้องใช้ AI

```bash

python3 scripts/build_data.py             # ตรวจข้อมูลคำศัพท์ (สคีมา/คำแปล/วลี)
python3 scripts/build_dialogues.py        # ตรวจบทสนทนา (79 บรรทัด/กฎเนื้อหา)
node scripts/e2e_test.mjs                 # ทดสอบจริง 105 ข้อในเบราว์เซอร์
node scripts/screenshot.mjs               # ภาพหน้าจอ
```
ทั้งหมดรันได้โดยไม่ต้องมี AI — ถ้าผ่าน = แอปยังดีอยู่

## 6. สิ่งที่ห้ามทำซ้ำ (เคยพังมาแล้ว — ดู `AGENTS.md` §9)

1. `document.createElement('svg')` → ไอคอนหายทั้งแอป (ต้องใช้ `createElementNS`)
2. `overflow:hidden` + 3D flip → ข้อความกลับด้าน
3. ปิด bottom sheet แล้ว re-render ทั้งหน้า → ความคืบหน้าหาย
4. กรองไฟล์เสียงด้วยขนาด > 800 ไบต์ → ประโยคสั้นถูกทิ้ง
5. ลืมอัปเดตคะแนนบนบับเบิล → คะแนนค้าง
6. `lookupWord` กับคำ ≤ 3 ตัวอักษร → ได้ IPA ผิดคำ
7. `Object.assign(el.style, {'--var': x})` → CSS variable ไม่ทำงาน

## 7. ข้อมูลผู้ใช้อยู่ที่ไหน (ถ้าจะย้ายเครื่อง)

- ความคืบหน้า/คำโปรด/SRS → `localStorage` (ย้ายด้วย **ตั้งค่า → ส่งออกข้อมูล** เป็น JSON)
- เสียงที่ผู้ใช้อัด → `IndexedDB` (ไม่ติดไปกับ export — ตั้งใจให้เป็นข้อมูลเฉพาะเครื่อง)
- ภาพ/ไฟล์เสียงของแอป → อยู่ในโฟลเดอร์ `data/` (คัดลอกตามไปได้เลย)
