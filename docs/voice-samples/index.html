  • Piper — ไลเซนส์ MIT ใช้เชิงพาณิชย์ได้ ทำงานออฟไลน์ได้ ไฟล์เล็ก → ปลอดภัยที่สุดถ้าจะขายจริง
  • Kokoro — Apache-2.0 ใช้เชิงพาณิชย์ได้ คุณภาพสูงกว่า แต่ช้ากว่า Piper ราว 8–9 เท่าบน CPU
  • Edge TTS — ฟรีและคุณภาพสูงสุด แต่เป็นบริการของ Microsoft ผ่านช่องทางที่ไม่ใช่ API ทางการ ควรใช้เพื่อทดลอง/ทำไฟล์ส่วนตัว ถ้าจะใช้เชิงพาณิชย์ให้ตรวจเงื่อนไขก่อน
  • Azure Speech (ชั้นฟรี F0) — 500,000 ตัวอักษร/เดือน ฟรี ใช้เชิงพาณิชย์ได้ตามเงื่อนไขบัญชี → เหมาะถ้าอยากได้เสียงระดับ Andrew/Brian แบบถูกต้องตามเงื่อนไข
