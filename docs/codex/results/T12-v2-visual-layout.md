แก้ได้ 4 ไฟล์ใน `v2/`:

- `v2/css/style.css` — ปรับสีและเงา, ระยะขอบ, แถบแท็บ, แถวคลังคำ และจัดจอฝึกเป็นเต็ม viewport พร้อมมาสคอสด้านขวาล่างที่ซ่อนเมื่อจอเตี้ย
- `v2/js/views-session.js` — ย้ายเนื้อหากับปุ่มตรวจเข้าโครง body/footer ใหม่ และลดขนาดมาสคอส
- `v2/js/views-me.js` — ปุ่มเสียงตัวอย่างหญิง/ชายส่ง `audioKey` ที่มีอยู่ใน manifest
- `v2/scripts/build_path.py` — เปลี่ยนสี Unit ครบตามชุดที่กำหนด

**ส่วนที่ตรวจได้:** ES modules ทั้ง 5 ไฟล์ที่เกี่ยวข้องผ่าน V8 parser และ `git diff --check` ผ่าน ความกว้างเนื้อหาที่คำนวณจาก padding 16px ต่อข้างคือ 288px ที่ viewport 320px, 328px ที่ 360px, 358px ที่ 390px และ 398px ที่ 430px; ค่านี้คำนวณจาก CSS ยังไม่ได้ยืนยันในเบราว์เซอร์

**ยังตรวจไม่ครบ:** ไม่มีคำสั่ง `python`/`node` ใน shell จึงรัน `build_path.py` ไม่ได้ และ `v2/data/path.json` ยังเป็นสีเดิม ผมไม่ได้แก้ JSON ด้วยมือเพราะกำหนดให้สร้างผ่านสคริปต์ ส่วน Chrome UI ถูกปฏิเสธ และ headless Chrome ปิดตัวจาก GPU ล้ม จึงยังยืนยัน overflow และ console errors จริงไม่ได้
