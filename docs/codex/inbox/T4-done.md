# T4 — ส่งมอบโหมดพูดตามเงา

## สรุป
เพิ่มหน้า `#/shadow` สำหรับเลือกบทฟัง ฝึกพูดตามทีละประโยค รับคะแนนเทียบคำ แสดงคำที่ยังไม่ชัด รองรับบันทึกเสียง/A-B และ fallback แบบให้คะแนนตัวเองเมื่อไม่มี SpeechRecognition บันทึก best score และบรรทัดที่ผ่านใน localStorage พร้อมทวน SRS เมื่อคะแนนยังไม่ถึงเกณฑ์

เชื่อมทางเข้าในหน้าเรียนและส่วน “ฝึกต่อ” ของหน้าวันนี้ เพิ่ม task `shadow` ใน 30 บทหลักสูตรที่มีข้อมูล listening และเพิ่ม E2E assertion ใหม่ 6 ข้อ

## ไฟล์ที่แตะ
- `js/views-shadow.js` — หน้ารายการ/ฝึก/สรุป shadow
- `js/listen-once.js` — ตัวช่วยรู้จำเสียงและบันทึกเสียงที่ใช้ร่วมกัน
- `js/views-speaking.js` — เปลี่ยนให้เรียกตัวช่วยเสียงร่วม
- `js/store.js` — `shadowProgress()` และ `saveShadowLine()` พร้อมกรองข้อมูลเสีย
- `js/micfallback.js` — callback เมื่อให้ดาว เพื่อบันทึกผล fallback
- `js/app.js` — route, title และแท็บ
- `js/views.js` — การ์ดทางเข้าในหน้าเรียน
- `js/views-today.js` — ทางลัดใน “ฝึกต่อ”
- `data/curriculum.json` — task shadow ใน 30 บทที่มี listening
- `scripts/validate_curriculum.py` — whitelist mode `shadow`
- `scripts/e2e_test.mjs` — เพิ่ม 6 assertion สำหรับ shadow

## ผลตรวจ
- `python scripts/validate_curriculum.py --strict`: ผ่าน — 5 levels, 15 units, 30 lessons; อ้างอิงบทฟังครบ 45/45
- `git diff --check`: ผ่าน
- ตรวจ import ภายในทั้งหมด 22 ไฟล์และ parse syntax ของไฟล์ JavaScript ที่เปลี่ยน 8 ไฟล์ผ่านใน Node runtime
- E2E: **ไม่ได้รัน** — เครื่องนี้ไม่มีคำสั่ง `node` ให้เรียกสคริปต์ และไม่มี Chrome CDP ที่ `127.0.0.1:9222` ให้เชื่อมต่อ จึงไม่มีบรรทัดสรุปผล E2E จริง

## วิธีตรวจด้วยมือ
1. เปิดแอปแล้วไป `#/shadow` ตรวจรายการบทและตัวกรองระดับ
2. เปิดบทแรก กด “ฟังต้นแบบ” หรือ “🐢 0.6×” แล้วกดไมค์พูดตาม
3. ลองประโยคที่พูดไม่ชัด ตรวจเปอร์เซ็นต์ ชิปคำ ปุ่มลองใหม่ และปุ่มข้ามหลังลองครบ 3 ครั้ง
4. ไปจนจบบท ตรวจเปอร์เซ็นต์เฉลี่ย/จำนวนผ่าน แล้วกลับรายการดู “ผ่านแล้ว x/y”
5. ปิด SpeechRecognition ในเบราว์เซอร์เพื่อทดสอบ fallback: อัดเสียง ฟัง A/B ให้ดาว และไปบรรทัดถัดไปเมื่อให้ 3 ดาวขึ้นไป

## ข้อจำกัด
การให้คะแนนใช้ Web Speech Recognition และเทียบระดับคำตาม `alignWords()`; เบราว์เซอร์ที่ไม่มี STT ใช้การอัดเสียงและประเมินตัวเอง ไม่มีการให้คะแนนอัตโนมัติ
