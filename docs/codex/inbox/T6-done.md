# T6 — ประโยคสำเร็จรูป

## สรุป

- เพิ่มคลัง 150 chunks ครบ 8 สถานการณ์: 18–19 ประโยคต่อกลุ่ม
- ระดับมีจำนวน A0 30, A1.1 45, A1.2 38, A2.1 22 และ A2.2 15
- เพิ่มหน้ากรองสถานการณ์/ระดับ ฟังเสียง ฝึกพูดพร้อมคะแนน ทำเครื่องหมายใช้ได้แล้ว และเรียนต่อ
- เก็บสถานะใน `localStorage` ผ่าน `store.chunks`; เพิ่มโหมด `chunks` ใน progress และเพิ่มคีย์ Kokoro `chunk:<id>`

## ไฟล์ที่แตะ

- `data/chunks.json`
- `scripts/validate_chunks.py`
- `scripts/generate_kokoro.py`
- `js/data.js`, `js/store.js`, `js/progress.js`, `js/views-chunks.js`, `js/views.js`, `js/app.js`
- `scripts/e2e_test.mjs`

## ผลตรวจ

- ตรวจข้อมูลด้วย PowerShell: `150` รายการ, ทุกสถานการณ์ 18–19 รายการ, สัดส่วนระดับตรงตามกำหนด, ความยาว 4–14 คำ, `keyPhrase` ตรงกับประโยค, note ไม่เกิน 60 ตัวอักษร, ไม่ซ้ำกันเอง และไม่พบประโยคตรงกับบทฟัง/บทสนทนาเดิม
- บรรทัดสรุปแทน validator: `DATA CHECK OK: 150 chunks; all counts, levels, phrases, and notes valid`
- `python scripts/validate_chunks.py --strict`: **ยังรันไม่ได้** — เครื่องมือนี้ไม่มีคำสั่ง `python` ใน PATH
- `node scripts/check_imports.mjs`, `node --check` และ `node scripts/e2e_test.mjs`: **ยังรันไม่ได้** — ไม่มีคำสั่ง `node` ใน PATH
- บรรทัดสรุป E2E: `NOT RUN — node executable unavailable`

## ตรวจด้วยมือ

1. เปิดแอปผ่านเซิร์ฟเวอร์ในเครื่อง แล้วไปที่ `#/chunks` หรือกด “ประโยคสำเร็จรูป” ในหน้าเรียน
2. ตรวจว่ามีรายการประโยคและตัวกรอง 8 สถานการณ์กับ 5 ระดับ; เลือก “คาเฟ่” แล้วดูว่ารายการลดลง
3. กด 🔊 เพื่อตรวจเสียง จากนั้นกด “พูดตาม” เพื่อทดสอบคะแนนหรือโหมดอัดเสียง/ให้ดาว
4. กด “ใช้ได้แล้ว”; ตรวจเครื่องหมาย ✓, ตัวเลขความคืบหน้า และปุ่ม “▶ เรียนต่อ” จากนั้นรีโหลดหน้าเพื่อยืนยันว่าความคืบหน้าคงอยู่
