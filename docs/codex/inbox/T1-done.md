# T1 — ดาวน์โหลดเสียงทั้งหมดไว้ใช้ออฟไลน์

## สรุป
เพิ่มแถว “ดาวน์โหลดเสียงทั้งหมด” ในกลุ่มตั้งค่าเสียง พร้อมจำนวนคลิปจาก manifest และขนาดประมาณ 3.6 MB สำหรับเสียงหนึ่งชุด
ดาวน์โหลดตามเพศเสียงที่เลือก โดยใช้เสียงหญิงเมื่อไม่มีเสียงที่เลือก และ fetch ทีละไฟล์ผ่าน service worker เดิม
แสดงความคืบหน้าบนแถวเดิม ปิดปุ่มระหว่างโหลด และป้องกันเริ่มงานซ้ำแม้เปิดหน้าตั้งค่าใหม่
แสดงสถานะสำเร็จหรือจำนวนไฟล์ที่พลาด พร้อมให้ลองใหม่ และแจ้งสุภาพเมื่อโหลดไม่ได้หรือไม่มีระบบแคช
ตรวจชนิดข้อมูลเพื่อไม่ให้หน้า HTML สำรองขณะออฟไลน์ถูกนับเป็นไฟล์เสียง

## ไฟล์ที่แก้หรือเพิ่ม
- `js/views.js` — เพิ่มแถวดาวน์โหลด การเลือกเสียง ความคืบหน้า การกันโหลดซ้ำ และการจัดการข้อผิดพลาด
- `scripts/e2e_test.mjs` — เพิ่ม assertion ว่ามีแถวดาวน์โหลดเสียงในหน้าตั้งค่า
- `scripts/test_audio_download.mjs` — เพิ่มการทดสอบผ่าน Chrome จริง ทั้งการจำลองข้อผิดพลาดและดาวน์โหลด/อ่านไฟล์จริงตอนออฟไลน์
- `docs/screenshots/t1-audio-download.png` — ภาพหน้าตั้งค่าบนขนาดหน้าจอมือถือหลังดาวน์โหลดครบ
- `docs/codex/inbox/T1-done.md` — รายงานส่งมอบนี้

## ผลตรวจสอบ
- `node --check js/views.js` ผ่าน
- `node --check scripts/e2e_test.mjs` และ `node --check scripts/test_audio_download.mjs` ผ่าน
- `node scripts/check_imports.mjs` ผ่าน: ตรวจ 38 จุดใน 17 ไฟล์ ไม่พบ import เสีย
- `CDP_PORT=9411 node scripts/e2e_test.mjs` ผ่าน 151/151 assertions พร้อม offline และ LIFF preview ไม่พบ JS error
- `node scripts/test_audio_download.mjs` ผ่าน: ความคืบหน้า, ปิดปุ่ม/กันกดซ้ำ, เปิดตั้งค่าใหม่ระหว่างโหลด, เลือกเสียงชาย/fallback หญิง, cache default, โหลดพลาดบางไฟล์/ทั้งหมด, HTML fallback และไม่มี Cache Storage
- ดาวน์โหลดไฟล์จริงครบ 491 คลิป ตรวจพบใน Cache Storage ครบ และปิดเครือข่ายแล้วอ่านเนื้อหาเสียงได้ครบ 491 คลิป ไม่พบ JS error

## วิธีตรวจด้วยมือ
1. เปิดเซิร์ฟเวอร์ในโฟลเดอร์โปรเจกต์ด้วย `python -m http.server 5173` แล้วเปิด `http://127.0.0.1:5173/` ใน Chrome
2. หากเป็นการเปิดครั้งแรก รอ service worker พร้อมแล้วโหลดหน้าใหม่ เปิดตั้งค่า เลือกเสียงหญิงหรือชาย
3. ตรวจแถว “ดาวน์โหลดเสียงทั้งหมด” แล้วกด “⬇ ดาวน์โหลด” ตัวเลข “กำลังโหลด N/491…” ต้องเดิน และปุ่มต้องกดซ้ำไม่ได้
4. ทดลองปิดแล้วเปิดตั้งค่าใหม่ขณะโหลด ปุ่มยังต้องปิดและแสดงความคืบหน้าของงานเดิม
5. รอจนขึ้น “✅ ดาวน์โหลดครบแล้ว” และ toast ยืนยัน 491 คลิป เปิด DevTools ดูว่าไม่มี JS error
6. ตั้ง Network เป็น Offline แล้วเปิดฟังคำหรือประโยคที่ยังไม่เคยฟัง ต้องได้เสียงจากไฟล์ที่ดาวน์โหลดไว้
7. กลับออนไลน์ เลือกอีกเพศเสียงแล้วดาวน์โหลดอีกครั้ง หากจำลองไฟล์บางส่วนโหลดไม่ได้ ต้องมีจำนวนที่พลาดและกดลองใหม่ได้

## ข้อจำกัดและขอบเขต
- ขนาด 3.6 MB เป็นค่าประมาณจากไฟล์ปัจจุบัน (หญิง 3,546,834 bytes / ชาย 3,348,699 bytes) ไม่ใช่การวัดพื้นที่ใช้งานของ Cache Storage แบบสด
- เก็บเฉพาะเสียงหนึ่งชุดตามตัวเลือกตอนเริ่มงาน ถ้าเปลี่ยนเสียงระหว่างโหลด งานเดิมจะโหลดชุดเดิมจนจบ ต้องกดดาวน์โหลดชุดใหม่อีกครั้ง
- ต้องมี Cache Storage และ service worker ที่ควบคุมหน้าอยู่ การเปิดครั้งแรกอาจต้องโหลดหน้าใหม่ก่อน
- สถานะปุ่มไม่ได้บันทึกข้ามการเปิดแอปใหม่ และแคชอาจถูกเบราว์เซอร์ล้างเมื่อพื้นที่ไม่พอ หรือล้างผ่านปุ่มล้างแคชเดิม
- ใช้ service worker เดิมแคชอัตโนมัติตามโจทย์ ไม่เพิ่มระบบตรวจพื้นที่หรือเปลี่ยนนโยบายแคช
- ไม่แก้ `js/version.js`, `sw.js`, `data/audio/**`, `data/*.json` หรือ `scripts/models/**` และไม่รันตัวสร้างข้อมูล/เสียงที่เขียนทับไฟล์เหล่านี้
