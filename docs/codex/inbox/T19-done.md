# T19 — รายงานส่งงาน

## สรุป
- เพิ่มปุ่มใบ้/ย้อนคำ/ล้างในแบบฝึกพิมพ์เดี่ยวและข้อพิมพ์ในบทเรียน พร้อมอัปเดตสถานะปุ่มตรวจเมื่อข้อความเปลี่ยน
- เพิ่มย้อนคำด้วยการแตะชิปที่เลือกในแบบเรียงประโยค พร้อมปุ่มล้างทั้งหมดและตัวนับคำ
- ขยายเป้าสัมผัส icon button, ปุ่มออก, คู่มือ Unit, ชิป และตัวเลือกคำตอบด้วย CSS; รักษากฎ `prefers-reduced-motion`
- เพิ่มป้าย aria ภาษาไทยให้ปุ่มไอคอน/ดาวที่แก้ และทำมาสคอสใน session เป็นภาพตกแต่งสำหรับ screen reader

## วิธีตรวจ
- ตรวจ diff และตรวจว่าปุ่มตรวจถูก disable เมื่อช่องพิมพ์ว่างและ enable เมื่อมีข้อความ
- ตรวจโค้ดเส้นทางย้อน/ล้างในแบบเรียงประโยค และค่า CSS ที่ตั้งเป้า 44px / 56px
- ยังไม่ได้รัน `node --check`, QA browser, หรือทดสอบ viewport จริง: คำสั่ง `node` ไม่มีใน PATH ของ environment นี้

## ข้อจำกัด
- การทดสอบ runtime และยืนยันไม่มี console error/ไม่มีล้นที่ 320/360/390/430px ยังต้องทำใน environment ที่มี Node และ browser QA พร้อมใช้งาน
- ไม่แก้ไฟล์นอก `v2/` ยกเว้นรายงานนี้
