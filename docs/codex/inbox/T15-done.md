# T15 — PangPood V2

## สรุป

- เพิ่มเวอร์ชันและ build date ในหน้า “เกี่ยวกับ” พร้อมปุ่มอัปเดตแอปและปุ่มทดสอบเสียง/ไมค์ที่แสดงผลจริง
- `playFile()` รอเปิด Web Audio chain, ลองเล่นซ้ำผ่าน `<audio>` ธรรมดาเมื่อ chain มีปัญหา, เก็บสาเหตุล่าสุดใน `audioDiagnostics()` และ fallback เป็น Web Speech เมื่อ MP3 เล่นไม่ได้
- เพิ่มเสียงตอบถูก/ผิดที่ต่างกัน, เสียงแตะปุ่ม และคงเสียงจบบทไว้ โดยเคารพ `settings().sfx`
- ข้อฝึกพูดตรวจไมค์ก่อนเรียก SpeechRecognition; ถ้า API หรือไมค์ใช้ไม่ได้จะเสนออัดเสียง ฟังกลับ และให้คะแนนตัวเอง 1–5 ดาว (ผ่านตั้งแต่ 3 ดาว) พร้อมปุ่มข้าม
- จัดโจทย์แนวตั้งกึ่งกลาง ย้ายมาสคอสไว้เหนือโจทย์ ปรับมาสคอสเป็น 84px, bubble padding 12px, ตัวเลือกสูงอย่างน้อย 52px และช่องไฟ 14px
- เพิ่ม `controllerchange` reload พร้อม flag ใน `sessionStorage` กัน reload ซ้ำ

## วิธีตรวจด้วยมือ

1. เปิด `v2/` ผ่าน localhost หรือ HTTPS แล้วไปหน้า “ฉัน” ตรวจเวอร์ชัน `PangPood v2.5.0 · build 2026-10-27`
2. แตะ “ทดสอบเสียง” และตรวจผล MP3 หรือข้อความวินิจฉัยเมื่อปิดเสียง/ไม่มีไฟล์
3. แตะ “ทดสอบไมค์” พูดระหว่างอัด 2 วินาที และตรวจว่าเสียงเล่นกลับพร้อมผลสถานะ
4. เข้าโจทย์และตอบถูก/ผิด ฟังเสียงสองแบบ; เข้าโจทย์พูด ทดสอบทั้งไมค์ที่อนุญาตและปฏิเสธ รวมถึงโหมดอัดเสียง/ให้ดาว/ข้าม
5. ตรวจหน้าเรียนที่ความกว้าง 320, 360, 390 และ 430px; เนื้อหาควรเรียงแนวตั้งและเลื่อนได้เมื่อความสูงจอไม่พอ
6. แตะ “อัปเดตแอป” แล้วตรวจว่าหน้าโหลดใหม่

## ผลตรวจและข้อจำกัด

- พบไฟล์ `v2/data/audio/f/word_feelings-kind.mp3` และ key ใน manifest
- `git diff --check` ผ่าน
- รัน `node --check` ไม่ได้: ไม่มีคำสั่ง `node` ใน PATH ของสภาพแวดล้อมนี้ และไม่พบ executable ในตำแหน่งติดตั้งมาตรฐานที่ตรวจไว้
- ยังไม่ได้ตรวจบนอุปกรณ์จริง/หลาย viewport; ควรตรวจด้วยขั้นตอนข้างต้นเมื่อมีเบราว์เซอร์และไมโครโฟน
- ไม่แก้ไฟล์นอก `v2/` ยกเว้นรายงานส่งงานนี้ตามตำแหน่งที่กำหนด
