# T14 — PangPood V2 เฟส 4

## สรุป

- เพิ่มตัวนับกิจกรรมรายวัน `lesson`, `review`, `words`, `speak`, `listen` ใน `pangpood-v2.activity` และผูกกับการตอบ/จบบทในระบบฝึก
- เควส 3 ข้อสุ่มแบบ deterministic ตามวันที่ มีเควสบทเรียนหรือทบทวนและเควสฟังหรือพูดเสมอ พร้อมแถบความคืบหน้าและรับ 20 XP ได้ครั้งเดียวต่อวัน
- เติมหน้าฉันด้วย XP, สตรีค, บทที่จบ, จำนวนคำถูกวันนี้, กราฟ 7 วัน, Section progress, ทางลัดทบทวน, ปรับเสียง, ปุ่มทดลองเสียงหญิง/ชาย, ข้อมูลเวอร์ชัน/ออฟไลน์ และรีเซ็ตแบบพิมพ์ยืนยัน
- เส้นทางแสดงตราเมื่อจบ Unit/Section และคู่มือ Unit แสดงคำศัพท์สูงสุด 5 คำพร้อมปุ่มฟัง

## วิธีตรวจ

- ตรวจ diff ว่าแก้เฉพาะไฟล์ V2 ที่ได้รับอนุญาตและรายงานส่งมอบ
- ไม่พบ `node` จึงรัน `node --check` ตามคำสั่งตรง ๆ ไม่ได้; ตรวจ parse ของไฟล์ JS ที่แตะทั้ง 5 ไฟล์ด้วย V8 runtime สำเร็จ
- ยังไม่ได้ทดสอบ flow/E2E หรือ console ใน browser

## ข้อจำกัด

- ควรรัน `node --check` กับไฟล์ JS ที่แตะและทดสอบ flow/console ใน browser ก่อนรวมงาน
- คีย์ข้อมูลหลักของ `store.js` คือ `pangpood-v2` (ไม่มีจุดท้ายตาม prefix ที่ระบุ) ปุ่มรีเซ็ตจึงลบคีย์ `pangpood-v2.*` และเรียก `store.resetAll()` เพื่อคืนค่าในคีย์หลักนี้เป็นค่าเริ่มต้น โดยไม่แตะคีย์ของแอปอื่น
