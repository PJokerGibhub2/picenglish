# T3b — โหมดฝึกฟัง

## สรุป

- เพิ่ม `#/listening` พร้อมรายการบท ระดับ ตัวกรอง ความคืบหน้า และลิงก์กลับหน้าเรียน
- เพิ่มบทเรียน 6 ขั้น ตั้งแต่เตรียมฟัง เล่นเสียงแยกตามบรรทัด ตอบคำถามพร้อม feedback เปิด transcript แบบไฮไลท์ เก็บคำเข้า SRS และสรุปเปอร์เซ็นต์
- ใช้ไฟล์ Kokoro ตามคีย์ `lis:<lessonId>:<lineIndex>` และ fallback เป็นเสียงเบราว์เซอร์เมื่อไม่มีไฟล์หรือเล่นไฟล์ไม่ได้; `fast=1` ข้ามเสียงสำหรับทดสอบ
- เพิ่มการ์ดฝึกฟังในหน้าเรียน ภารกิจ “ฟัง 1 บท” และ `store.bumpListening()` สำหรับสถิติรายวัน/สถานะบทที่ทำแล้ว

## ไฟล์ที่แตะ

## ผลตรวจ

- เพิ่ม E2E assertion ใหม่ 6 ข้อ ครอบคลุมรายการบท, คำถามนำ/เริ่มฟัง, สถานะกำลังเล่น, feedback, transcript และสรุปเปอร์เซ็นต์
- `git diff --check` สำหรับไฟล์ที่แตะ: ผ่าน
- `node --check` และ `node scripts/check_imports.mjs`: ไม่สามารถรันได้ เพราะ shell ปัจจุบันไม่มี `node` executable
- `node scripts/e2e_test.mjs`: ไม่สามารถรันได้ด้วยเหตุผลเดียวกัน จึงยังไม่มีบรรทัดสรุปผล E2E ที่คัดลอกได้
- ไม่ได้สร้างภาพหน้าจอใหม่ เพราะสคริปต์ screenshot ใช้ Node เช่นกัน

## วิธีตรวจด้วยมือ

1. เปิดแอปแล้วเข้า `#/learn` จากนั้นแตะการ์ด “ฝึกฟัง”
2. เลือกระดับหรือแตะบท เช่น “ทักทายเพื่อนบ้าน”
3. ดูคำถามนำและชิปคำศัพท์ จากนั้นแตะ “เริ่มฟัง” และ “▶ เล่นบทฟัง”
4. ตอบคำถาม ตรวจ feedback ทันที แล้วไปหน้า transcript เพื่อแตะบรรทัดและดูไฮไลท์
5. เพิ่มคำเข้า SRS และตรวจหน้าสรุป; สำหรับทดสอบแบบไม่รอเสียง ใช้ `#/listening?id=lis-daily-01&fast=1`

## ข้อจำกัด

- ยังไม่ได้รัน browser E2E, syntax check หรือ import check ใน environment นี้ เนื่องจากไม่มี Node.js ให้เรียกใช้งาน
- ไฟล์เสียงบางบทอาจยังไม่มีใน manifest/ดิสก์ ระบบจึงใช้ Web Speech API สำรองตามที่กำหนด
