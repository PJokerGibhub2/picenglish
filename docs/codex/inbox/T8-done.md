# T8 — ภารกิจรายวันและบทสนทนาเรียนต่อเนื่อง

## สรุป

- เพิ่ม `js/quest.js` สร้างแผน 3 ภารกิจจากวันที่ ระดับ และความคืบหน้าของโหมดต่าง ๆ พร้อมค่าเป้าหมาย ความคืบหน้า และเวลาประมาณ
- หน้า “วันนี้” แสดงภารกิจจากแผน พร้อมแถบความคืบหน้า ลิงก์ไปโหมดที่เกี่ยวข้อง ปุ่มเริ่มภารกิจแรกที่ยังไม่เสร็จ และสถานะ/มาสคอต/Toast เมื่อทำครบ
- เพิ่มตัวนับรายวันของ shadow, chunks และ dictation โดยข้อมูลเก่าจะได้ค่าเริ่มต้นเป็น 0
- เพิ่มการ์ดเรียนต่อในรายการบทสนทนา และตั้งให้เปิดบทถัดไปหลังสรุป 2 วินาที พร้อมปุ่มยกเลิกและล้าง timer เมื่อออกจากหน้า
- เพิ่ม E2E assertions สำหรับแผน 3 ข้อ การแสดงและเส้นทางภารกิจ ตัวนับรายวัน สถานะครบภารกิจ การ์ดเรียนต่อ และ auto-advance

## ผลตรวจ

- `git diff --check`: ผ่าน
- `node scripts/check_imports.mjs`: รันไม่ได้ — เครื่องนี้ไม่มีคำสั่ง `node` ใน PATH (`node : The term 'node' is not recognized...`)
- `node --check` ไฟล์ที่แก้: รันไม่ได้ด้วยเหตุเดียวกัน
- `node scripts/e2e_test.mjs`: รันไม่ได้ด้วยเหตุเดียวกัน จึงไม่มีบรรทัดสรุป E2E ให้คัดลอก และยังยืนยันจำนวน assertions ที่ผ่านหรือการไม่มี JS error จากเบราว์เซอร์ไม่ได้

## วิธีตรวจด้วยมือ

1. เปิดแอปและไปหน้า “วันนี้” ตรวจว่ามี 3 ภารกิจ พร้อมตัวเลขและแถบความคืบหน้า
2. แตะภารกิจแต่ละข้อเพื่อตรวจว่าเปิดโหมดที่ระบุ และทำกิจกรรมให้ครบเพื่อดูสถานะ “✓ ครบภารกิจวันนี้” กับ Toast
3. เปิด “บทสนทนา”, เริ่มสถานการณ์แล้วออกก่อนจบ ตรวจการ์ด “▶ เรียนต่อ” จากรายการ จากนั้นทำบทให้จบเพื่อดูตัวนับถอยหลังและการไปบทถัดไป; ทดสอบปุ่ม “ยกเลิก” และออกจากหน้าในช่วงนับถอยหลัง

## ข้อจำกัด

ยังไม่ได้รัน import check, syntax check หรือ E2E เพราะ runtime `node` ไม่มีใน PATH ของสภาพแวดล้อมนี้ ต้องรันคำสั่งเหล่านี้ในเครื่องที่มี Node.js ก่อนรวมงาน ส่วน `js/version.js`, `sw.js` และ `data/**` ไม่ได้แก้ไข
