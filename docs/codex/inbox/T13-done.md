# T13 — PangPood V2 เฟส 3

## สรุป

- เพิ่มข้อฟังความหมายและคำถามจากบรรทัดที่ตรงกันในบทฟัง จำกัดบทฟังไว้ไม่เกิน 3 ข้อ
- เพิ่มข้อบทสนทนา 2 แบบ: ฟังแล้วเลือกคำแปลไทย และฟังบรรทัดของผู้เรียนแล้วเลือกประโยคอังกฤษ
- เพิ่ม `#/review` ใช้คำ SRS ที่ถึงกำหนดก่อน และใช้ข้อที่เคยตอบผิดเป็นทางสำรอง พร้อมสรุปและ XP
- เพิ่มทางเข้าทบทวนจากหน้าเควสและหน้า “ฉัน” และเปลี่ยน node ของบท `kind: review` เป็นมงกุฎพื้นสีเหลือง

## วิธีตรวจด้วยมือ

1. เปิด `v2/` ผ่าน local HTTP server แล้วไป `#/lesson?id=u2-l4`; ตรวจว่ามี `dialog-line` สองข้อและปุ่ม “ฟังซ้ำ”
2. ไป `#/lesson?id=u1-l2`; ตรวจข้อ `line-listen` และ `listen-question` พร้อมเสียงบรรทัด
3. ไป `#/review`; เล่นจนจบ แล้วตรวจสรุป/XP; หากไม่มีคำถึงกำหนดและไม่มีข้อผิด ให้เห็นมาสคอต sleep กับข้อความ “วันนี้ทบทวนครบแล้ว”
4. ตรวจการ์ดทบทวนในหน้าเควสและหน้า “ฉัน” และ node มงกุฎของบท review ในเส้นทาง
5. เปิด Console ตรวจว่าไม่มี error

## ผลตรวจในสภาพแวดล้อมนี้

- ตรวจโครงสร้างข้อมูล: `u2-l4` ชี้ไป `dlg-cafe`; บรรทัดบทสนทนาใช้ `thai` และ `alternative[]`; `u1-l2` อ้างถึง `lis-cafe-04` ซึ่งมี transcript/questions
- ยังรัน `node --check` ไม่ได้ เพราะไม่มี `node.exe` ใน PATH ของสภาพแวดล้อม
- ยังเปิด browser ตรวจหน้าจอและ Console ไม่ได้: browser provider ใน CUA ไม่มีให้ใช้งาน และการเลือกหน้าต่าง Google Chrome ถูกระบบปฏิเสธ

## ข้อจำกัด

- รายการ SRS ใช้ `dueWords(db.words, 10)`; เมื่อไม่มีคำ due จะใช้ข้อที่บันทึกไว้ใน `pangpood-v2.review` จากการตอบผิด
- การตรวจเปิดจริงและ console error ต้องทำซ้ำในเครื่องที่มี Node.js และ browser พร้อมใช้งาน
