- **ห้ามแตะโฟลเดอร์ `v2/` เด็ดขาด** (นั่นคือ PangPood เวอร์ชัน 2)
- ห้ามเปลี่ยนเนื้อหา/ข้อมูล/เสียง/ตรรกะการให้คะแนน — **แก้เฉพาะ CSS + aria-label**

## ที่มา
ผลตรวจ `node scripts/qa/qa_audit.mjs --version v1` (ดู `docs/qa/v1-audit.md`):
- **0 JS error** ทุกจอ
- พบ **38 จุด** ที่ปุ่ม/ชิปเล็กกว่า 44px (ส่วนใหญ่: ปุ่มไอคอน 38×38, ชิป 40px สูง, ปุ่มเล็กในหน้าจอฝึก)
- ปุ่มไอคอนบางตัวไม่มี `aria-label`

## งานที่ต้องทำ

### 1) `css/style.css` — เพิ่ม/ปรับกฎ (ต่อท้ายไฟล์ได้)
ให้ครอบคลุมปุ่มทุกชนิดใน V1 (คลาสที่มีอยู่จริง: `.btn`, `.btn-block`, `.btn-ghost`, `.icon-btn`, `.chip`, `.kv`, `.answer`, `.mtile`, `.kv`, `.pill`, `.tab`, `.flip-btn`, `.mic-btn` ฯลฯ — ตรวจในไฟล์ก่อน):
```css
/* มาตรฐานการแตะ 44px (WCAG 2.2 target size) */
.icon-btn, .btn-icon { min-width: 44px; min-height: 44px; }
.btn { min-height: 44px; }
.chip, .pill-btn, .kv { min-height: 44px; }
.answer, .mtile { min-height: 56px; }
```
- **ระวัง**: อย่าให้ `.pill` (ป้ายข้อความ) สูงขึ้นจนเพี้ยน — ถ้า `.pill` ใช้แสดงสถานะ ให้ยกเว้น
- ตรวจว่าหน้าจอไม่ล้นที่ความกว้าง 320px (`.row` ที่มีหลายปุ่มต้อง `flex-wrap: wrap` หรือลด padding)
- ปุ่มไอคอนที่มีแต่ไอคอนอยู่แล้ว (เช่น 🔊 ★ ←) ให้คงขนาด ≥44px

### 2) เติม `aria-label` ให้ปุ่มไอคอน
ใน `js/*.js` (ไม่ใช่ v2/) หาปุ่มที่ `textContent` เป็นอีโมจิ/สัญลักษณ์อย่างเดียว แล้วเติม `'aria-label'` ภาษาไทย เช่น
- `🔊` → `'ฟังเสียง'`
- `★` / `☆` → `'บันทึกเป็นคำโปรด'`
- `←` → `'ย้อนกลับ'`
- `✕` → `'ปิด'`
- `🔁` → `'ฟังซ้ำ'`
- `🐢` → `'ฟังช้า ๆ'`
- `⚙️` → `'ตั้งค่า'`
(แก้เฉพาะจุดที่ไม่มี aria-label อยู่แล้ว — ห้ามรื้อโครงสร้าง)
