อ่านก่อน: `v2/js/views-session.js`, `v2/js/views-path.js`, `v2/js/mascot2.js`, `v2/js/ui2.js`, `v2/js/sfx.js`, `v2/css/style.css`

### สถานะล่าสุด (v2.6.0)
- จอเรียนแนวตั้งกึ่งกลาง · มาสคอสบน คำถามกลาง คำตอบล่าง · เสียงถูก/ผิดแล้ว · หน้าตั้งค่ามีเวอร์ชัน/ทดสอบเสียง/ไมค์
- ยังขาด "ความลื่น" แบบเกม: เปลี่ยนข้อไม่มีแอนิเมชัน, ปุ่มไม่มีการกด, ไม่มีคอนเฟตตีตอนจบ Unit, มาสคอสไม่ขยับตอนผู้ใช้เงียบ

## งานที่ต้องทำ

### 1) แอนิเมชันเปลี่ยนข้อ (`views-session.js` + CSS)
- ทุกครั้งที่ขึ้นข้อใหม่: เนื้อหา (`content`) เล่นแอนิเมชัน `session-in` 180–220ms (opacity 0→1 + translateY 10px→0)
- ตอนกดตรวจ: ฟองคำพูด/โจทย์ไม่กระตุก — ผลลัพธ์ (feedback) เล่น `feedback-in` 160ms (scale .98→1 + fade)
- ปุ่มตัวเลือกเมื่อถูกเลือก: `transform: scale(.985)` 60ms + ขอบหนาขึ้น (มี `.selected`)
- ห้ามใช้แอนิเมชันกับ `prefers-reduced-motion: reduce` (ปิดทั้งหมด)

### 2) คอนเฟตตี + มาสคอส
- **จบบท**: มี `confetti()` อยู่แล้ว → เพิ่มให้มาสคอส `cheer` 2.4s (มี) + ข้อความสรุปมีอนิเมชันนับเลข % ขึ้น (เช่น 0→83 ใน 500ms)
- **จบ Unit** (บทที่ 5 ของ Unit, นับจาก `progress2.unitDone()` = 5): เมื่อกลับไปหน้าเส้นทาง ให้เล่น `confetti()` ครั้งเดียว + toast "จบ Unit … แล้ว 🎉" (เก็บ flag ใน localStorage `pangpood-v2.unitCelebrated` = `{unitId: true}`)
- **ตอบถูก 3 ข้อติดกัน**: มาสคอส `cheer` 800ms + toast เล็ก "ต่อเนื่อง 3 ข้อ! 🔥" (ไม่ต้องมีระบบคอมโบเต็ม)

### 3) มาสคอสมีชีวิตตอนผู้ใช้เงียบ (`views-session.js`)
- ถ้าไม่มีการกดอะไร 18 วินาที → เปลี่ยนสถานะมาสคอสเป็น `sleep` + ข้อความใต้ ("พังหลับแล้ว… แตะเพื่อไปต่อ") · แตะที่ใดก็ได้ → กลับ `idle`
- ถ้าตอบถูก → `cheer` (มี) · ตอบผิด → `sad` 900ms (มี) — ต้องกลับ `idle` อัตโนมัติ

### 4) หน้าเส้นทางให้มีชีวิต
- node ที่กำลังทำ: เด้งเบา ๆ (มี) · เมื่อกด node ที่ล็อก → **สั่นเบา ๆ** (`.shake` 300ms) + toast (มี toast อยู่แล้ว)
- Unit ที่จบแล้ว: ตราประทับ "✓ จบ Unit" ปรากฏด้วยแอนิเมชัน `stamp-in` (scale 1.6→1 + rotate -8deg→0, 260ms)
- เลื่อนจอลงถึง node ปัจจุบันอัตโนมัติเมื่อเปิดหน้า (เฉพาะครั้งแรกที่เข้าหน้า, `scrollIntoView({block:'center'})`)

### 5) รายละเอียดเล็ก ๆ ที่ทำให้ดูแพง
- ปุ่มทุกปุ่ม: `:active { transform: translateY(2px) }` + เงาลดลง (มีใน `.btn3d` แล้ว — ตรวจให้ครบทุกปุ่มรวม `.chip-btn`, `.answer`, `.node`)
- แถบความคืบหน้า: เปลี่ยนความกว้างด้วย transition 260ms
- ตัวเลข XP ในหน้าสรุป: อนิเมชันนับขึ้นเช่นกัน
