## งานที่ต้องทำ

### 1) ลบระบบภาพออกจากแอป
- **ลบไฟล์** `js/images.js`, `js/art.js` และโฟลเดอร์ `data/art/` (96 SVG) ออกจากโปรเจกต์
- ลบ import/การเรียกที่เกี่ยวข้องทั้งหมด (`photoBox`, `artFor`, `artImgElement`, `loadArtManifest`, `photoFor`, `fetchCandidates`, `prefetchOfflinePhotos`, `audit` ฯลฯ)
- `index.html` / `js/app.js`: ลบการเรียก `loadArtManifest()`
- `sw.js`: ลบ `./data/art/manifest.json` และไฟล์ art ออกจาก precache (**ห้ามแตะ VERSION**)
- **ลบออกจากหน้าตั้งค่า**: แถว "ภาพประกอบ" (art/photo/emoji), เครดิต OpenMoji, และแถว "ดาวน์โหลดภาพออฟไลน์"
- `js/store.js`: ลบ setting `imageMode`, `showPhotos` (ถ้ามี) — ต้องไม่ทำให้ข้อมูลเดิมพัง (อ่านค่าเก่าได้แต่ไม่ใช้)
- ตรวจว่าไม่มี string "Wikimedia", "OpenMoji", "ภาพถ่าย" เหลือใน UI

### 2) การ์ดคำศัพท์แบบ text-first (ต้องสวย ไม่โล่ง)
สร้างคอมโพเนนต์กลางใน `js/ui.js` (หรือ `js/wordcard.js` ถ้าเหมาะ):
```js
export function wordHero(word, { size = 'lg' }) → element
```
หน้าตา:
- **แถบสีหมวด** ด้านบน (ใช้ `--cat` จาก `categoryOf(word.category).color` ที่มีอยู่)
- **Monogram**: ตัวอักษรแรกของคำ ตัวใหญ่ (~72px) ในวงกลม/สี่เหลี่ยมมน พื้นจางสีหมวด
- `word` ตัวใหญ่ (font-en, ~34px, หนา) · `ipa` · `thai` (~19px) · `pos` tag
- ใช้ใน: **แฟลชการ์ด** (หน้า/หลัง), **หน้าฟังประโยค**, **ควิซ** (หัวข้อคำถาม), **หน้าคำของฉัน**, **หน้าฝึกออกเสียง**
- ควิซ/จับคู่: เอารูปออก → ตัวเลือกเป็นข้อความล้วน (จับคู่ = คำอังกฤษ ↔ คำไทย)
- ห้ามเว้นที่ว่างที่เคยเป็นรูป — จัดให้กระชับและอ่านง่าย

### 4) ทดสอบ (`scripts/e2e_test.mjs`)
- **ลบ/แก้ assertion ที่เกี่ยวกับภาพเดิม**: เช่น "ภาพกราฟฟิกโหลดจากไฟล์ในเครื่อง (data/art/)", "มีปุ่มดาวน์โหลดภาพออฟไลน์", "สลับเป็นโหมดภาพถ่ายจริง", "แผงเลือกภาพ", "ภาพถัดไป (ปุ่มเปลี่ยนภาพ)"
- **เพิ่มใหม่ 4 ข้อ**:
  1. ไม่มี element รูปภาพในหน้าแฟลชการ์ด (`#view img` = 0)
  2. การ์ดมี monogram + คำ + IPA + ไทย ครบ
  3. หน้าตั้งค่าไม่มีแถว "ภาพประกอบ" และไม่มีคำว่า OpenMoji/Wikimedia
  4. ควิซ/จับคู่ทำงานได้โดยไม่มีรูป
- ต้องผ่านทั้งชุด (ของเดิมที่เหลือ + ใหม่)
