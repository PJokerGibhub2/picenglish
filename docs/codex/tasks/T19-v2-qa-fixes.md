## งานที่ต้องทำ

### 1) แถบเครื่องมือในจอพิมพ์ (`v2/js/views-chunk-drill.js` + จอพิมพ์ใน `views-session.js`)
เพิ่มแถวปุ่มใต้ช่องพิมพ์ (สูง ≥44px, ป้ายชัด, aria-label ครบ):
- **💡 ใบ้** — เผยคำถัดไป 1 คำ (เติมลงช่องให้อัตโนมัติ) · ใช้ได้ไม่จำกัด แต่บันทึกว่าใช้ใบ้
- **↩︎ ย้อนคำ** — ลบคำสุดท้ายของสิ่งที่พิมพ์
- **🗑 ล้าง** — ล้างทั้งช่อง
- ปุ่ม **ตรวจ** ยังอยู่ล่างสุด
- กดใบ้/ย้อน/ล้าง ต้องได้ `sfxTap()` และไม่ทำให้ปุ่มตรวจพัง (`disabled` ต้องอัปเดตตาม)

### 2) จอเรียงประโยค (`#/chunks/order` + ข้อ `chunk-order` ใน session)
- แตะชิปที่อยู่ในประโยค → **ย้ายกลับลงคลังคำ** (undo)
- ปุ่ม **🗑 ล้างทั้งหมด** → คืนชิปทุกตัว
- แสดงจำนวนคำที่เลือก / ทั้งหมด (`3/7 คำ`)

### 3) ขยายปุ่มให้แตะง่าย (ทั้ง V2)
- ปุ่มไอคอนทุกตัว (`.icon-btn`, ปุ่มออก ✕, ปุ่มตั้งค่า, ปุ่มคู่มือ Unit) → **44×44px** (hit area)
- ชิป (`.chip`, `.chip-btn`, `.tile`) → **สูง ≥44px**
- ปุ่มตัวเลือกคำตอบ (`.answer`) → **สูง ≥56px**
- ตรวจว่าไม่มีอะไรล้นจอที่ 320/360/390/430px และไม่ทำให้หน้าจอดูโปร่งเกินไป (คงระยะห่างที่สมดุล)

### 4) aria-label ครบ
- ปุ่มที่มีแต่ไอคอน (✕, 🔊, ★, ←, 🔁, 🐢, 🗑, ↩︎, 💡) ต้องมี `aria-label` เป็นภาษาไทย
- รูปมาสคอสมี `aria-hidden` หรือ `aria-label` ที่เหมาะสม

### 5) อย่าทำให้ของเดิมพัง
- ห้ามแก้ logic การให้คะแนน/SRS/XP
- ต้องคง `prefers-reduced-motion`
- `node --check` ผ่านทุกไฟล์
