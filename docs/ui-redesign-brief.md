# UX/UI Brief — ยกระดับหน้าตาให้ "พรีเมียม" แบบ ELSA Speak

> สถานะ: **คุยกันก่อน ยังไม่ลงมือ** · อ้างอิงจากภาพหน้าจอ ELSA Speak ที่ผู้ใช้ส่งมา 5 ภาพ
> เป้าหมาย: ให้ PicEnglish ดูพรีเมียม น่าใช้ และเหมาะกับมือถือ — **โดยไม่ลอกแบรนด์หรือจริยธรรมที่ไม่ดีของเขา**

---

## 1. ถอด "ภาษาภาพ" ของ ELSA จากภาพ (สิ่งที่ทำให้ดูพรีเมียม)

| # | สิ่งที่เห็นในภาพ | ทำไมมันได้ผล | เราทำได้ไหม |
|---|---|---|---|
| 1 | **พื้นหลังไล่สีเข้ม (navy→ม่วง) + แสงเรือง (glow)** | ดำ/เข้ม = รับรู้ว่าพรีเมียม ประหยัดสายตา และทำให้สีเน้นเด้ง | ✅ CSS gradient + radial glow |
| 2 | **หนึ่งหน้า = หนึ่งการตัดสินใจ** (CTA ใหญ่ปุ่มเดียว) | ลดภาระสมอง ผู้ใช้ไม่ต้องเลือก | ✅ |
| 3 | **ปุ่ม/การ์ดใหญ่ผิดปกติ** (~90–110px สูง, การ์ดตอบ 2 ใบใหญ่เท่าจอ) | กดง่ายด้วยนิ้วโว้ง ไม่พลาด | ✅ |
| 4 | **มาสคอต 3D เงาผิว (glossy orb + แว่น)** เป็นจุด emotive | ทำให้แอป "มีชีวิต" และเป็นที่จดจำ | ⚠️ ทำได้แบบ 2.5D ด้วย SVG ไล่เงา (ของเราต้องเป็นตัวละครของเราเอง) |
| 5 | **แถบความคืบหน้าบางด้านบน + ตัวนับ 3/5 + XP** | รู้สึกคืบหน้าและได้รางวัล | ✅ |
| 6 | **ผลเฉลยทันทีและเฉพาะเจาะจง** (การ์ดแดง + IPA `/liːf/` ใต้คำ) | ผู้ใช้เห็นว่าผิดตรงไหน ไม่ใช่แค่ "ผิด" | ✅ (มีระบบเทียบคำอยู่แล้ว) |
| 7 | **หน้าฉลอง + สตรีค 7 วัน** (เปลวไฟ + จุด S M T W T F) | แรงจูงใจกลับมาใช้วันพรุ่งนี้ | ✅ (มีข้อมูล daily อยู่แล้ว) |
| 8 | **ฟอนต์หนา ตัวใหญ่ ไม่มีกรอบรก** | อ่านง่าย ไม่ต้องเพ่ง | ✅ |
| 9 | **การ์ดโปร่งแสง + เส้นขอบจาง 8% + เงานุ่ม** | ดูมีมิติ ไม่แข็ง | ✅ |
| 10 | **ราคา/เงื่อนไขบอกตรงไปตรงมา** (ราคาเรียกเก็บครั้งถัดไป ยกเลิกได้) | สร้างความไว้ใจ | ✅ (ใส่ในส่วนของเรา) |

**สรุป**: ความพรีเมียม = *พื้่นเข้ม + ที่ว่างเยอะ + ตัวใหญ่ + หนึ่ง CTA + แสงเงาที่คุมโทน* — ทั้งหมดทำได้ด้วย CSS

## 2. Design tokens ที่จะใช้ (ค่าจริง พร้อมใส่ใน `css/style.css`)

### สี
```css
/* พื้นหลังแบบพรีเมียม (dark) */
--bg-0: #0E0A1F;      /* เข้มสุด (ขอบจอ) */
--bg-1: #16102E;      /* พื้นหลังหน้า */
--bg-2: #221A42;      /* การ์ด */
--bg-3: #2C2352;      /* การ์ดยกขึ้น / hover */
--glow: #5B3DF5;      /* แสงเรืองม่วง (radial) */
--glow-2: #14B8A6;    /* แสงเรืองเขียวน้ำทะเล */

/* สีเน้น (ใช้ให้น้อย แต่มั่นใจ) */
--accent: #3B82F6;    /* ปุ่มหลักฟ้า (แบบ ELSA) */
--accent-press: #2563EB;
--success: #34D399;
--danger: #F87171;
--gold: #FBBF24;      /* สตรีค/XP */

/* ตัวอักษร */
--text: #F5F3FF;
--text-soft: #B4ADCB;
--text-dim: #7C7597;

/* เส้นขอบ/เงา */
--stroke: rgba(255,255,255,.10);
--stroke-strong: rgba(255,255,255,.18);
--shadow-card: 0 12px 32px rgba(0,0,0,.38);
```

### ระยะ/มุมโค้ง/ขนาดตัวอักษร
```css
--r-card: 24px;   --r-sheet: 28px;  --r-btn: 999px;   /* ปุ่มแคปซูลแบบ ELSA */
--space-1: 4px; --space-2: 8px; --space-3: 12px; --space-4: 16px;
--space-5: 24px; --space-6: 32px; --space-7: 48px;
--fs-display: 34px; --fs-h1: 26px; --fs-h2: 20px; --fs-body: 16px; --fs-cap: 13px;
--tap-min: 92px;   /* ความสูงขั้นต่ำของตัวเลือก/ปุ่มหลัก */
```

### โมชัน
```css
--ease-out: cubic-bezier(.16,1,.3,1);     /* เร็วตอนออก ช้าาตอนจบ = ดูแพง */
--dur-fast: 140ms; --dur-mid: 240ms; --dur-slow: 420ms;
```
- กดการ์ด → `scale(.98)` 140ms
- เปลี่ยนหน้า → fade + slide-up 12px (240ms)
- ถูก/ผิด → เด้งเบา ๆ (scale 1 → 1.03 → 1) + สี
- มาสคอต → หายใจ/กระพริบตา (3–4 วิต่อรอบ), ยิ้มเมื่อผ่าน, เงยหน้าเมื่อพลาด

## 3. คอมโพเนนต์ที่ต้องมี (ของใหม่)

| คอมโพเนนต์ | ลักษณะ |
|---|---|
| **LessonShell** | แถบบน: ปุ่มปิด ✕ · แถบความคืบหน้าบาง · ตัวนับ 3/5 · ชิป XP |
| **Mascot** | ตัวละคร SVG 2.5D ของเราเอง (มี 4 อารมณ์: idle / happy / sad / celebrate) ~5–8 KB |
| **OptionCard** | การ์ดคำตอบสูง ≥ 92px · ขอบจาง · เลือกแล้วเรืองฟ้า · ถูก=เขียว/ผิด=แดง + แสดง IPA |
| **FeedbackBar** | แถบล่างบอกผล + ปุ่มเดียว "ดำเนินการต่อ" เต็มความกว้าง |
| **Celebration** | หน้าฉลอง: มาสคอต + สตรีค + แถว 7 วัน (S M T W T F S) + XP + ปุ่มแชร์/ไปต่อ |
| **StreakWeek** | จุด 7 วัน (ทำแล้ว=ส้ม ✓, วันนี้=เรือง, อนาคต=จาง + ?) |
| **PriceCard** (ไม่บังคับ) | ถ้าจะมี "รุ่นพรีเมียม" ในอนาคต — ใช้ของเราที่ไม่กดดัน |

## 4. แมปหน้าจอ: ELSA → แอปเรา

| หน้าจอ ELSA (ในภาพ) | หน้าจอเราที่จะได้ลุคเดียวกัน |
|---|---|
| ข้อสอบการฟัง (ภาพ 3) — การ์ด 2 ใบ + ปุ่มเสียง | **ควิซปรนัย** และ **บทสนทนา** (การ์ดตัวเลือกคำตอบ) |
| ผลเฉลย (ภาพ 4) — แดง + IPA | **ผลการพูด/ควิซ** (มีอยู่แล้ว: ถูก/ผิด + IPA + คำที่ยังไม่ชัด) |
| หน้าฉลอง + สตรีค (ภาพ 5) | **สรุปบทสนทนา** และหน้าใหม่ **"วันนี้"** |
| แถบความคืบหน้า + XP (ภาพ 4) | ทุกโหมดเรียน (มี progress bar แล้ว ขาด XP/ลุค) |
| หน้าราคา (ภาพ 1–2) | **ไม่ทำตอนนี้** — แอปเราฟรี และไม่อยากใช้ความกดดันแบบนั้น |

## 5. สิ่งที่ **ไม่ลอก** (และเหตุผล)

| ไม่ลอก | เพราะ |
|---|---|
| **มาสคอต/โลโก้ของ ELSA** | ลิขสิทธิ์และเครื่องหมายการค้า — เราต้องมีตัวละครของเราเอง |
| **"Mega Deal 85% OFF / Live Now"** | เป็นการกดดันด้วยเวลาปลอม (dark pattern) ขัดหลัก "gentle UX" ของเรา |
| **คะแนนระดับเสียง (phoneme)** | ต้องมีโมเดลเฉพาะทาง — เราใช้ "สื่อสารได้/ไม่ได้" + เทียบเสียง A/B แทน |
| **หัวใจ/เสียชีวิต (hearts)** | ทำให้ผู้ใช้กลัวพลาด — ขัดเป้าหมายลดความกลัวพูด |

## 6. แผนงาน 3 ระยะ (ถ้าตกลง)

| ระยะ | ทำอะไร | เวลา | เห็นผลอย่างไร |
|---|---|---|---|
| **A — ภาษาภาพ** | design tokens + ธีมมืดพรีเมียม + Mascot SVG + LessonShell | ~1.5 วัน | ทุกหน้าดู "พรีเมียม" ทันทีโดยไม่ต้องรื้อโค้ด |
| **B — หน้าจอหลัก 4 หน้า** | บทสนทนา · ควิซ · ผลเฉลย · สรุป/สตรีค | ~2 วัน | ได้ลุคแบบ ELSA เต็มรูปแบบในหน้าที่ยังใช้บ่อยที่สุด |
| **C — ขัดเงา** | transition, เสียงเอฟเฟกต์ (สร้างจาก WebAudio ไม่ต้องโหลดไฟล์), สั่นเบา ๆ, empty state, dark/light สลับ | ~0.5–1 วัน | รู้สึก "แพง" ตอนใช้งานจริง |

**หมายเหตุสำคัญ**: ระยะ A เพียงอย่างเดียวก็เปลี่ยนภาพรวมได้มาก — แนะนำทำ A ก่อนแล้วดูของจริง

## 7. เรื่องที่ต้องตัดสินก่อนลงมือ

1. **ธีม**: มืดเป็นค่าเริ่มต้น (แบบ ELSA) + มีโหมดสว่างให้เลือก / หรือคงสว่างเป็นหลัก?
2. **มาสคอต**: ตัวละครของเราเอง (ผมวาด SVG ให้ 4 อารมณ์) — อยากได้สไตล์ไหน: นกฮูก / นกแก้ว / หุ่นยนต์กลม ๆ / แมว?
3. **เกมมิฟิเคชัน**: ใส่ **XP + สตรีค** (แนะนำ) แต่ **ไม่ใส่หัวใจ/การลงโทษ** — ตกลงไหม?
4. **ขอบเขต**: เริ่มจากระยะ A (ทั้งแอปได้ลุคใหม่) หรือลุคใหม่เฉพาะ "โหมดฝึกพูด/บทสนทนา" ก่อน?
5. **หน้าตาแบบไหน**: อยากให้ผมทำ **mockup ภาพนิ่ง 2–3 หน้า** ให้ดูก่อนเขียนโค้ดจริงไหม?
