สิ่งที่ต่างเมื่ออยู่ใน LINE

  • ไม่มีแถบที่อยู่ (URL bar) — ได้พื้นที่จอเพิ่ม
  • มีแถบปิด (✕) ของ LINE ด้านบน และพื้นที่ปลอดภัยด้านล่าง (safe area) — แอปเผื่อระยะไว้แล้ว
  • แถบหัวแสดง ชื่อผู้ใช้ LINE แทนที่ว่าง (เข้าสู่ระบบอัตโนมัติ ไม่ต้องกรอกอะไร)
  • มีปุ่ม 💚 แชร์ให้เพื่อนใน LINE ในหน้าตั้งค่า
  • ไมโครโฟน (โหมดฝึกพูด) ใช้ได้ แต่ iOS ใน LINE อาจขอสิทธิ์ไม่ผ่าน — ใช้เบราว์เซอร์หลักถ้าจะฝึกออกเสียง

รูปการ์ดตัวอย่าง (og:image) จะใช้ภาพหน้าจอแฟลชการ์ดเมื่อ deploy จริง

เปิดเป็น LIFF จริงต้องทำอะไร

  1. Deploy แอปให้ได้ URL แบบ https://… (Vercel/Netlify/Cloudflare — ฟรี)
  2. เข้า developers.line.biz/console → สร้าง Provider → Create a LIFF app
  3. ใส่ Endpoint URL = URL ที่ deploy · Size = Full · Scopes = profile, openid
  4. คัดลอก LIFF ID ไปวางใน index.html ที่ <meta name="liff-id">
  5. เปิด LIFF URL บนมือถือ → ใช้งานได้ทันที (โค้ดพร้อมแล้ว ไม่ต้องแก้เพิ่ม)

ยังไม่ต้องสมัครอะไรก็ดูหน้าตาได้จากหน้านี้ (โหมดจำลอง)
