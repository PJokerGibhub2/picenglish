# ลิงก์ถาวรฟรี — วิธีเอาแอปขึ้นออนไลน์ (ทำครั้งเดียว ~3 นาที)

> เป้าหมาย: ได้ URL แบบ `https://…` ที่**อยู่ถาวร** เปิดบนมือถือได้จริง ใช้ฟรี ไม่ต้องใช้บัตรเครดิต
> ไฟล์ที่ต้องใช้: **`picenglish-site.zip`** (0.31 MB — อยู่ในโฟลเดอร์เดียวกับ `english-picture-app`)

---

## ✅ วิธีที่แนะนำ: Netlify Drop (ฟรี · ไม่ต้องใส่บัตร · 3 นาที)

1. สมัครฟรีที่ <https://app.netlify.com/signup> (อีเมลหรือ Google ก็ได้ — **ไม่ต้องใช้บัตร**)
2. ไปที่ <https://app.netlify.com/drop>
3. **ลากไฟล์ `picenglish-site.zip` ไปวางในกรอบ** แล้วรอ ~20 วินาที
4. ได้ URL ทันที เช่น `https://sparkly-panda-123456.netlify.app`
5. เปลี่ยนชื่อให้จำง่าย: **Site configuration → Change site name** → เช่น `picenglish` → ได้
   `https://picenglish.netlify.app`
6. เปิด URL บนมือถือ → เมนูเบราว์เซอร์ → **เพิ่มไปยังหน้าจอหลัก** (จะได้ไอคอน+เปิดเต็มจอเหมือนแอป)

**ทำไมต้องสมัครก่อนอัปโหลด**: ถ้าลากแบบไม่ล็อกอิน ระบบจะสร้างไซต์แบบ “ยังไม่ยืนยันเจ้าของ”
ซึ่งอาจถูกเก็บกวาดภายหลัง — สมัครฟรีก่อนแล้วไซต์จะอยู่ถาวรและคุณแก้ไขเองได้

### อัปเดตเวอร์ชันใหม่ภายหลัง
- วิธีง่าย: **Deploys → Drag and drop** แล้วลาก zip ใหม่ทับ (Netlify เก็บประวัติให้)
- หลังอัปเดต ให้ **เพิ่มเลข `VERSION` ใน `sw.js`** (เช่น `v5` → `v6`) ไม่งั้นมือถือที่เคยเปิดจะยังใช้แคชเก่า

## 📱 หลังได้ลิงก์แล้ว — ตรวจ 4 อย่าง

| ตรวจ | วิธี |
|---|---|
| **HTTPS** | Netlify/Vercel/Cloudflare ให้ HTTPS ฟรีอัตโนมัติ ✓ (ต้องมี https ไมค์จึงทำงาน) |
| **ไมโครโฟน** | เปิดแอป → ฝึกพูด → บทสนทนา → กดไมค์ → อนุญาต |
| **ออฟไลน์** | เปิดแอปครั้งแรกให้โหลดครบ → ปิดเน็ต → เปิดใหม่ยังใช้ได้ (service worker) |
| **ติดตั้งเป็นแอป** | เบราว์เซอร์ → เพิ่มไปยังหน้าจอหลัก (iOS: ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม) |

## ⚠️ ข้อควรรู้

- **ห้ามเปิดด้วย `file://`** (ดับเบิลคลิก index.html) — ต้องเป็น http/https เท่านั้น
- ชื่อไซต์ฟรีจะถูกใช้ร่วมกัน (เช่น `picenglish.netlify.app` อาจมีคนใช้แล้ว → เติมเลขต่อท้าย)
- หลังอัปเดตบ่อย ๆ ให้ bump `VERSION` ใน `sw.js` ทุกครั้ง
- ข้อมูลผู้ใช้ (ความคืบหน้า/เสียง) เก็บในเบราว์เซอร์ของแต่ละเครื่อง — ไม่ได้อยู่บนเซิร์ฟเวอร์
- ถ้าจะใช้เชิงพาณิชย์จริงจัง ค่อยย้ายไปโดเมนของตัวเอง (ซื้อโดเมน ~300–450 บาท/ปี แล้วชี้มาที่ Netlify)

| อาการ | สาเหตุ/ทางแก้ |

| อัปแล้วขึ้น 404 | zip ต้องมี `index.html` อยู่ที่ **ระดับบนสุด** (ของเราถูกต้องแล้ว) |

| เห็นเวอร์ชันเก่า | ปิดแท็บแล้วเปิดใหม่ / เพิ่มเลข `VERSION` ใน `sw.js` |
