# โหมดพูดตามเงา (Shadowing) — สเปก v1

> เป้าหมาย: ให้ผู้เรียน **พูดตามเจ้าของภาษาแบบทันที** เพื่อฝึกจังหวะ การเชื่อมเสียง และความคล่อง
> ใช้ของที่มีอยู่แล้ว: บทฟัง 45 บท (`data/listening.json`) + เสียง Kokoro รายบรรทัด (`lis:<id>:<line>`) + ระบบให้คะแนนคำ (`listenOnce`/`evaluate`)

---

## 1. สองโหมดย่อย

| โหมด | ทำอะไร | ให้คะแนนไหม |
|---|---|---|
| **พูดตามทีละประโยค (Sequential)** | ฟัง 1 บรรทัด → พูดตาม → ระบบเทียบคำ → ผ่าน/ลองใหม่ | **ให้คะแนน** (word-level) |
| **พูดพร้อมกัน (Simultaneous)** | เปิดเสียงพร้อมพูดทับ → อัดเสียง → ฟังเทียบ A/B → ให้ดาวตัวเอง | ไม่ให้คะแนน (ข้อจำกัดของเบราว์เซอร์) |

> ตาม `AGENTS.md` ข้อ 7: simultaneous วัดอัตโนมัติไม่ได้ (เสียงลำโพงรั่วเข้าไมค์) → ใช้ A/B + self-rating

---

## 2. การไหลของ 1 ครั้ง (4–6 นาที)

```
เลือกบท (ตามระดับ) → [บรรทัดที่ 1..N]
   ① ฟังต้นแบบ (0.6×/0.85×/1.0×, เล่นซ้ำได้ไม่จำกัด)
   ② กดไมค์ → พูดตาม → ได้ % + คำที่ยังไม่ชัด
        - ผ่าน (≥ passThreshold) → ไปบรรทัดถัดไป
        - ไม่ผ่าน → ปุ่ม "ฟังช้า ๆ อีกครั้ง" + "ลองใหม่" (ไม่จำกัด แต่แสดงความพยายามที่ 3+)
        - iOS/ไม่มี STT → สลับเป็น A/B + ให้ดาวตัวเอง (ใช้ micPanel ที่มีอยู่)
   ③ (ไม่บังคับ) ฟังเสียงตัวเองเทียบต้นแบบ
→ สรุป: จำนวนบรรทัดที่ผ่าน · % เฉลี่ย · คำที่ควรทวน (เข้า SRS) · ปุ่ม "บทถัดไป"
```

---

## 3. กติกา UX

- ไม่มีคำว่า "ตก" — ใช้ "พูดได้ 62%" + "ลองอีกครั้งได้เลย"
- ฟังซ้ำไม่จำกัด ไม่มีค่าปรับ
- ข้ามบรรทัดได้เสมอ แต่บันทึกว่ายังไม่ผ่าน (เพื่อมาทวน)
- มาสคอต/เสียง chime ให้กำลังใจ (มี `sfxSuccess`/`sfxSoft` แล้ว)

---

## 4. จุดเชื่อมกับระบบเดิม

| ระบบ | ใช้อย่างไร |
|---|---|
| `js/speech.js` | `audioUrl('lis:<id>:<i>', gender)` + `sayText` fallback + `createRecognizer`/`alignWords` |
| `js/views-speaking.js` | ใช้ `listenOnce()`/`evaluate()` แนวคิดเดิม (คัดลอก logic หรือแยกเป็นโมดูลกลาง) |
| `js/store.js` | `bumpSpoken()`, `addSecondsSpoken()`, `gradeSentence()` (เก็บคำที่พลาด) |
| `js/recorder.js` | อัดเสียง + A/B (`playBlob`) + `saveRecording` |
| หลักสูตร | เพิ่ม task mode `shadow` ใน lesson ที่มี `content.listening` |

---

## 5. หน้าจอ

- **#/shadow** — รายการบทที่พูดตามได้ (จาก listening.json) + ตัวกรองระดับ + สถานะ (ผ่านกี่บรรทัด)
- **#/shadow?id=<lessonId>** — จอเล่น: แถบความคืบหน้าบรรทัด, ประโยคต้นแบบ (en + th), ปุ่มเล่น/ช้า, ปุ่มไมค์ใหญ่, ผล %, ปุ่มถัดไป
- สรุปท้ายบท: เกจ % เฉลี่ย + รายการบรรทัดที่ยังไม่ผ่าน + ปุ่มทวนเฉพาะบรรทัดนั้น

---

## 6. ข้อมูลที่ต้องเพิ่ม (เล็กมาก)

- `store.shadowProgress[lessonId] = { passed: [lineIdx...], best: {lineIdx: pct}, updatedAt }`
- ไม่ต้องสร้างเนื้อหาใหม่ (ใช้ listening.json) — **ประหยัดเวลาและไฟล์เสียง**
