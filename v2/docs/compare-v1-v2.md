## 6) ข้อควรตัดสินใจ

1. **จะใช้เวอร์ชันไหนเป็นตัวหลัก** — V1 เนื้อหาแน่นกว่า (โหมดฝึกเฉพาะทางครบ), V2 ให้ความรู้สึกเป็นเกมและมีเส้นทางชัด
2. ถ้าเลือก V2 → ควรย้ายโหมดที่ยังมีเฉพาะ V1 (ฝึกออกเสียง/บทสนทนาแบบเต็ม/ทบทวนประโยค) เข้า V2 ในรอบถัดไป
3. ถ้าเลือก V1 → เก็บ V2 ไว้เป็น "โหมดเกม" ทางเลือก (ลิงก์จาก V1) ได้
4. ทั้งสองเวอร์ชันแชร์คอนเทนต์ชุดเดียวกัน → อัปเดตคำศัพท์/บทฟังที่เดียวใช้ได้ทั้งคู่ (ผ่าน `sync`)
