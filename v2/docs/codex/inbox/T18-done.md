# T18 — งานที่ทำเสร็จ

## สรุป

- เพิ่มหน้าพูดตามเงา 45 บท พร้อมกรองระดับ, บันทึกคะแนนรายบรรทัด, ทางเลือกอัดเสียงฟัง A/B และสรุปผล
- เพิ่มคลังประโยค 150 รายการ พร้อมกรองสถานการณ์/ค้นหา, ฟัง, ทำเครื่องหมายว่าใช้ได้แล้ว และลิงก์ไปแบบฝึก
- เพิ่มแบบฝึกพิมพ์ตามพร้อมผลรายคำ และแบบเรียงชิปที่ชี้ตำแหน่งแรกที่ผิดพร้อมคำใบ้
- เพิ่มทบทวนประโยคจากตัวอย่างคำและคลังประโยค ใช้ API SRS จริง (`srsOfSentence`, `gradeSentence`) รอบละไม่เกิน 10 ข้อ และสรุป XP
- เปิดการ์ดทั้ง 6 ใบในหน้า “ฝึก” และเพิ่ม route ใหม่ใน router

## วิธีตรวจ

- ตรวจ API ที่ใช้ใน `store.js`, `speech.js`, `listen-once.js` และข้อมูล JSON ก่อนเชื่อมหน้าใหม่
- ตรวจ route และไฟล์ที่เปลี่ยนด้วยการอ่านทบทวน
- ยังรัน `node --check` และ E2E ไม่ได้: เครื่องที่ทำงานไม่มี `node`/`nodejs` ใน PATH (`node` command not found)
- ยังไม่ได้ตรวจในเบราว์เซอร์ จึงยังยืนยัน console และหน้าจอ 390px ไม่ได้

## ข้อจำกัด

- โหมดอัดเสียง A/B ต้องอาศัยสิทธิ์ไมโครโฟนและ MediaRecorder ของเบราว์เซอร์
- รายการรีวิวเลือกประโยคใหม่ที่ยังไม่เคยมี SRS (`due: 0`) รวมกับรายการถึงกำหนด เพื่อให้ผู้ใช้เริ่มสะสมประวัติทบทวนได้
- โปรดรัน `node --check` กับไฟล์ JS ใน `v2/js/` และ `v2/scripts/e2e.mjs` ในเครื่องที่มี Node ก่อนส่งใช้งาน
