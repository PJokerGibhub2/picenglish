# T17 — ย้ายฟีเจอร์ V1 เข้า V2 (รอบ 1/3)

## สรุป

- เพิ่มแท็บล่างลำดับที่ 3 “ฝึก” รวม 6 โหมด โดยเปิดได้แล้ว 3 โหมด: ฝึกออกเสียง, บทสนทนา และฟังบทเต็ม
- เพิ่มฝึกคำ/ประโยค แบ่งชุดละ 10 ข้อ เลือกหมวดได้ ให้คะแนนผ่านที่ 70% บันทึก SRS และกิจกรรมพูด รองรับอัดเสียง ฟังเทียบ และให้คะแนนตัวเองเมื่อเบราว์เซอร์ไม่มี STT
- เพิ่มบทสนทนา 8 สถานการณ์ ใช้บทและวลีจากข้อมูลเดิม เลือกประโยคทางเลือก พูดให้คะแนน สลับบท บันทึกตำแหน่งและสถานะจบ
- เพิ่มฟังบท 45 เรื่อง กรองระดับ เล่นพร้อมไฮไลท์คาราโอเกะ ตอบคำถาม สรุปผล บันทึกคะแนน และไปบทถัดไปได้
- เพิ่ม API `loadListening()`, `loadChunks()` และ `listeningById()` ซึ่งคืนข้อมูลจาก cache ใน `db` หลังโหลดชุดข้อมูล

## วิธีตรวจ

- ตรวจ JavaScript ที่แก้ด้วย parser V8 ในสภาพแวดล้อมนี้ โดยถอดเฉพาะ syntax ของ ES module (`import`/`export` และ `import.meta`) ก่อนส่งให้ parser: ผ่านทุกไฟล์
- ไม่สามารถเรียก `node --check` หรือ E2E ได้ เพราะเครื่องมือนี้ไม่มี `node`/`node.exe` อยู่ใน PATH หรือในตำแหน่งติดตั้งมาตรฐานที่ตรวจพบ
- ยังไม่ได้ตรวจ UI ในเบราว์เซอร์จริง

## ข้อจำกัด

- ตามข้อกำหนดไม่ได้แก้ `v2/sw.js` และ `v2/js/version.js`; ไฟล์ view ใหม่จึงยังไม่อยู่ในรายการ precache ของ service worker (จะถูกเก็บ cache เมื่อโหลดผ่านเครือข่ายสำเร็จ)
