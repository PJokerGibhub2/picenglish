# T11 — Session Engine เสร็จแล้ว

## สรุป

- เพิ่มตัวสร้างแบบฝึกที่สุ่มและสลับข้อ โดยไม่ใช้เนื้อหาซ้ำในชุดเดียวกัน และพยายามกระจายประเภทข้อให้หลากหลาย
- เพิ่มหน้าฝึกเต็มจอพร้อมเสียงซ้ำ, ตัวเลือก, เรียงชิป, พิมพ์ตามเสียง, ฝึกพูดเมื่อเบราว์เซอร์รองรับ, feedback, เฉลย, XP, สรุป และไปบทถัดไปอัตโนมัติใน 3 วินาที
- ข้อที่ตอบผิดถูกเก็บใน `localStorage` คีย์ `pangpood-v2.review` เพื่อทบทวนภายหลัง
- แตะ node ที่ปลดล็อกแล้วบนเส้นทางเพื่อเข้า `#/lesson?id=...`; node ที่ผ่านแล้วยังเล่นซ้ำได้
- ไฟล์ทั้งหมดที่แก้หรือเพิ่มอยู่ใน `v2/` เท่านั้น

## ไฟล์ที่แตะ

- `v2/js/session.js`
- `v2/js/views-session.js`
- `v2/js/app.js`
- `v2/js/views-path.js`
- `v2/js/views-words.js`
- `v2/css/style.css`

## วิธีตรวจด้วยมือ

1. เปิด `v2/index.html` ผ่าน local HTTP server
2. เปิด `#/lesson?id=u1-l1` หรือแตะบทแรกบนหน้าเส้นทาง
3. เลือกคำตอบและกดตรวจ; ลองตอบผิดเพื่อดูเฉลยและปุ่มลองอีกครั้ง/ต่อไป
4. เล่นจนจบเพื่อตรวจเปอร์เซ็นต์, คะแนนข้อ, XP และการไปบทถัดไป; ปุ่มยกเลิกหยุดการไปต่ออัตโนมัติ
5. ออกจากบทกลางทางเพื่อดูหน้าถามยืนยัน; กลับเส้นทางหลังจบบทเพื่อตรวจเครื่องหมายผ่าน

## ข้อจำกัดการตรวจ

- ไม่สามารถรัน `node --check` ได้: เครื่องมือ `node`, `nodejs`, `deno`, `bun` และ Python ไม่อยู่ใน PATH ของสภาพแวดล้อมนี้
- การตรวจหน้าใน Chrome ถูกปฏิเสธโดยระบบอนุมัติ Computer Use จึงยังไม่ได้ยืนยันการเล่นจริงหรือ console ในเบราว์เซอร์
- การฝึกพูดจะปรากฏเฉพาะเมื่อ `sttSupported()` เป็นจริง; Speech Recognition ของเบราว์เซอร์อาจต้องใช้อินเทอร์เน็ตตามข้อจำกัดของแพลตฟอร์มเดิม
