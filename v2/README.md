# PangPood · พังพูด — Version 2 (เกมเรียนภาษาอังกฤษ)

> PWA เรียนพูดภาษาอังกฤษสำหรับคนไทย เรียนรู้แบบ "เดินเส้นทาง" กับช้างน้อย **พัง**
> ออฟไลน์ 100% · ไม่มีโฆษณา · ไม่มี backend · ข้อมูลอยู่ในเครื่องผู้ใช้เท่านั้น

- **ที่อยู่**: https://pjokergibhub2.github.io/picenglish/v2/
- **เวอร์ชัน**: ดูที่ `js/version.js` (แสดงใน topbar และหน้าฉัน → เกี่ยวกับ)
- **Version 1** (PicEnglish) ยังอยู่ที่ https://pjokergibhub2.github.io/picenglish/ และ **ไม่ถูกแก้ไข**

---

## ทำไมต้องมี V2

V1 เป็น "คลังคำศัพท์ + โหมดฝึก" ที่ผู้ใช้ต้องเลือกเองว่าจะเรียนอะไร
V2 เปลี่ยนปรัชญาเป็น **เกมเส้นทาง (path)** แบบ Duolingo:

| ประเด็น | V1 (PicEnglish) | V2 (PangPood) |
|---|---|---|
| การนำทาง | แท็บ 5 อัน + รายการโหมด | **แท็บ 4 อัน** (เส้นทาง · เควส · คลังคำ · ฉัน) + เส้นทางเป็นหน้าหลัก |
| บทเรียน | เลือกบทจากรายการ | **node บนเส้นทาง** (ล็อก/กำลังทำ/ผ่าน/มงกุฎ) |
| ในบท | ทีละแบบฝึก | **ชุด 10 ข้อผสม** จากคำ/ประโยค/บทฟัง/บทสนทนา |
| แรงจูงใจ | XP + สตรีค | XP + สตรีค + **เควส 3 ข้อ/วัน** + ตรา Unit |
| มาสคอส | โรบอต "ปิโก" (SVG) | **ช้างน้อย "พัง"** (SVG แยกชิ้น + 7 ท่าแอนิเมชัน) |
| ภาพประกอบ | ไม่มี (text-first) | ไม่มี (text-first เช่นกัน — ตามนโยบายลิขสิทธิ์) |
| โทนสี | ม่วง-น้ำเงินพรีเมียม | **เขียวสด/เหลือง/คอรอล** แบบเกม |
| เสียง | Kokoro 2 เสียง | **Kokoro 2 เสียงเดิม** (af_heart / am_adam) |

## รันและทดสอบ

```bash
# 1) เสิร์ฟที่ root ของโปรเจกต์
python -m http.server 5173

# 2) เปิด Chrome แบบ debug
chrome --headless --remote-debugging-port=9411 \
  --use-fake-ui-for-media-stream --use-fake-device-for-media-stream about:blank

# 3) รันชุดทดสอบ V2 (31 ข้อ)
node v2/scripts/e2e.mjs

# 4) สร้างเส้นทางใหม่หลังแก้ข้อมูล
python v2/scripts/build_path.py
```

## กติกาที่ต้องรักษา

1. **ไม่แตะ V1** — ทุกไฟล์ของ V2 อยู่ในโฟลเดอร์ `v2/` เท่านั้น
2. **ข้อมูลแยก**: localStorage ของ V2 ใช้คำนำหน้า `pangpood-v2.` (ห้ามใช้คีย์ของ V1)
3. **ไม่มีภาพจากภายนอก** — มาสคอสวาดเองด้วย SVG, ไอคอนเป็น SVG inline
4. **เสียง 2 เสียงเท่านั้น**: `af_heart` (หญิง) และ `am_adam` (ชาย)
5. **ไม่มีหัวใจ/จำกัดการเล่น** — ผิดได้ไม่จำกัด, ข้ามได้เสมอ (gentle UX)
6. **ทำงานออฟไลน์** — service worker scope `/v2/`, cache ชื่อ `pangpood-*`
7. **ภาษาไทยใน UI** อังกฤษเฉพาะเนื้อหาบทเรียน
